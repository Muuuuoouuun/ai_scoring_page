# AIs 디자인 보정 기준

2026-09-12 사용자 피드백: 테마·톤은 유지하되 유아용처럼 보이는 표현을 줄이고, 멘트를 간결하게 정리하며, 밀도와 여백을 조정한다. 앱 상세에는 점수·기능·유사 앱을 구성한다.

## 시각 방향

- 노랑·코발트 블루·아이보리 조합은 유지한다. 노랑은 브랜드·선택 상태·필요한 강조에 사용하고 본문은 밝은 중립 표면으로 읽기 편하게 한다.
- 두껍고 둥근 디스플레이 글꼴, 손그림 밑줄, 로고 주변 장식, 과장된 모노그램, 스티커 형태의 배지와 큰 버튼을 줄인다.
- 일반 한글 산세리프의 보통·중간·세미볼드 굵기를 사용한다. 페이지 제목 30–34px, 영역 제목 18–21px, 본문 14–16px를 목표로 한다.
- 주요 영역 사이는 28–36px 정도로 구분하고 표·목록 행은 40–48px 정도로 정리한다. 의미 없는 빈 영웅 영역을 줄이며 정보 단위가 바뀌는 곳에는 여백을 확보한다.
- 가벼운 구분선과 정렬을 먼저 쓰고, 기능적 이유가 있는 곳에만 테두리·면 색상을 둔다. 모든 정보를 카드로 감싸지 않는다.

위 값은 향후 구현을 위한 목표이며 생성 이미지에서 픽셀 단위 구현을 검증했다는 뜻은 아니다.

## 기존 페이지에 적용할 문구

| 위치 | 기존 표현 | 보정 표현 |
| --- | --- | --- |
| 개인 페이지 | 내 도구들이 모이는 곳 | 내 서비스 |
| 랭킹 | 같은 일을 하는 도구를 비교해보세요 | 업무별 저장 순위 |
| 정보 | 알아두면 좋은 AI 정보 | AI 정보 |
| 커뮤니티 | 경험을 나누면, 선택이 쉬워져요 | 커뮤니티 |
| 추천 | 나에게 맞는 방법 찾기 | 추천 |
| 추천 유형 | 지금 쓰는 Draft로 시작하기 | 현재 도구 활용 |
| 추천 유형 | 비슷한 도구 비교하기 | 유사 앱 비교 |
| 추천 유형 | 함께 쓰는 방법 살펴보기 | 도구 조합 |
| 질문 행동 | 질문 남기기 | 질문 작성 |
| 저장 행동 | 써보고 싶은 도구를 모아보세요 | 도구함에 저장 |

설명이 필요할 때는 적용 조건·제약·행동을 한 문장으로 쓴다. 예: ‘Pro 요금제에서 지원’, ‘출처 정확성 확인’, ‘공식 서비스에서 실행’. 감탄·격려·반복적인 ‘~해보세요’ 문구를 줄인다.

## 앱 상세 정보 구조

1. 앱 개요: 이름, 한 줄 설명, 플랫폼·언어·요금제, 서비스 열기, 도구함 저장.
2. 업무별 평가: 항목별 5점 척도, 선택한 업무, 플랜·버전, 평가일, 표본과 검토자, 평가 기준·결과.
3. 주요 기능: 기능명, 지원 여부, 플랜·파일 형식 등 조건. 미확인은 0점이나 미지원으로 처리하지 않는다.
4. 유사 앱: 현재 앱과 겹치는 업무와 차이, 비교 행동. 현재 앱을 포함해 최대 세 개를 나란히 비교한다.
5. 보조 정보: 요금제 구조, 공식 문서, 출처·확인일.

이번 시안은 가상 앱 Draft를 사용하며 모든 점수·기능·요금제·대안은 예시다. 종합 100점이나 개인 적합도 백분율을 새로 만들지 않고, 평가 항목과 근거를 보여준다. 기존 페이지의 실제 UI 코드는 변경하지 않았다.
