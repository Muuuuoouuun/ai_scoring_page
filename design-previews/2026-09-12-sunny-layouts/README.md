이 표의 번호는 이번 레이아웃 생성 결과가 채팅에 표시된 순서입니다. 이전 테마 선택 번호와 별개입니다.

| 번호 | 레이아웃 | 원본 |

공통 제품 요소: 네 가지 주요 메뉴, 내 도구함 / 내 서비스, 검색 범위 표시, 개인 서비스 상태, 저장한 활용 안내, 구독·비용 링크, 비공개 안내. 서비스명과 기록은 디자인 비교용 가상 예시입니다. 세 번째 시안은 서비스 선택 후 상세 상태이며, 네 번째는 기획서의 업무별 모음을 중심에 둔 상태입니다.

검토: 참조 테마와 결과 네 개를 육안으로 대조하고, 주요 한글 문구·메뉴·배치·콘텐츠 잘림 여부를 확인했습니다. 1487×1058px 원본을 크기 변경 없이 복사했습니다. 실제 동작하는 UI 구현은 포함하지 않습니다.
