## 페이지별 구성

- 랭킹: 업무와 기간, 저장 수 정렬, 비교 선택, 집계 기준. 저장 수를 도구 성능 점수로 해석하지 않도록 구별합니다.
- 정보: 활용 가이드와 소식, 가이드 읽기, 출처·확인일 확인 경로.
- 커뮤니티: 후기와 선택 질문, 예시 작성자와 예시 글, 질문 남기기, 공개 범위 안내.
- 추천: 명시한 관심 업무, 기존 도구 활용·대안 비교·도구 조합, 추천 이유와 요금제 확인 조건, 피드백.
