## E10의 증거 범위 점검

- D10의 기존 고정 게이트 판단과 28개 주 화면 대응표를 대조했다. E10의 두 PASS는 실제 이미지를 읽은 테마 비평·주 화면 D/M 위계 관찰에 한정된다. 모든 폼·상태·상호작용이 완비됐다는 주장으로 바꾸지 않았다.
- 실패 캡처 03/11/12/46/77과 잘못된 하단 캡처 108을 제외하고, 유효한 대체 관찰을 구분한다. 긴 이미지에서 작은 문구를 판독하지 못한 한계, 로컬 QA 자료와 배포 자료, root와 독립 검토자의 직접 판독 범위를 명시한다.
- `2026-09-12-v10-production-visual-review.md`의 99–104 독립 검토와 맞는다. 99는 로컬 실제 정산 구간이고 100–104는 당시 배포 뉴스·앵커·검색·관리자 표다. 관리자 양끝 열 관찰이 기존 공백을 보완하되 전체 확장 상태 완료로 확대되지 않는다.
- `observations.jsonl`의 105–113은 localhost이며, E10도 이를 로컬 후속 관찰로 기록한다. 109/110의 정상 날짜 계산과 111의 중복 적용일 충돌은 별도 메모리 재현 보고서 `/private/tmp/ais-v11-terms-preview-repro.md`의 엔진/API 결과와도 일치한다. 본 점수 검증에서 105–113 이미지를 새로 열거나 브라우저 조작을 다시 했다고 주장하지 않는다.
- `3.4.4`는 83의 저장 비교 세부 조건·경고 등 남은 확장 화면 공백 때문에 계속 UNVERIFIED다. 실제 200% 확대, 스크린리더, 외부 비회원, 독립 계정/기기, 실제 이메일/무인 운영을 수행했다고 쓰지 않았다. 오류 안내의 `role=alert`가 실제 스크린리더 검증으로 승격되지 않았다.
- 마지막 재열람에서 최종 배포 추기가 추가되어 있었다. **Sites 버전 12**, 배포 `appgdep_6aa536c7e918819190bec1d9e2073c7d`, 성공 `2026-09-12T11:26:55.039392Z`, 환경 revision 2가 JSON `sourceContext` 및 root 전달과 일치한다. 본 작업은 배포 도구를 새로 조회한 독립 성공 검증이 아니라 기록 간 대조다.
- E10은 최종 배포 홈 새로고침과 후속 충돌 안내의 로컬 112/113 검증을 명시적으로 구분한다. 최종 추기의 114 홈·콘솔/Worker 재확인·임시 탭 정리도 root 관찰로 기록돼 있다. `queued`인 패널 요청을 실제 전면 표시로 바꾸어 쓰지 않았다. 앞선 첫 배포 후 0건 관측도 별도로 남아 있다.
- 최종 추기 후 작은 기록 공백 하나를 root에게 전달했다. `114-final-production-home-viewport.png` 파일은 존재하지만 이 재열람 시점의 `observations.jsonl`은 113에서 끝났다. E10의 “URL·시각·문서 폭은 observations에 보관” 일반문구에 114의 예외를 명시하거나 실제 보유 메타데이터를 추가하면 된다. 이 항목은 최종 홈 캡처의 기록 연결 보강이며, 기존 28개 주 화면 증거·두 점수 변경을 무효화하지 않는다. 누락 수치를 추정하거나 이번 평가자가 114를 직접 판독했다고 주장하지 않았다.

이번 변경으로 기존의 지연·추천 관련성·운영 공백이 해소됐거나 전체 목표가 완료됐다는 주장은 없다. 현재 점수표와 E10을 이 제한된 의미로 사용하는 데 추가 점수 정정은 필요하지 않다.
