## 개인정보와 회귀

공개 추가 데이터는 실행일·agent-ui·행수·익명 연습 결과뿐이다. 실제 Notion URL/페이지·카드 ID, 계정/워크스페이스 이름, QA 페이지 이름, 이메일, 원본 스크린샷·감사 파일 링크는 세 파일 변경에 없다. 기존 공식 Notion 안내 링크만 유지한다. 내부 증거 보고서에 있는 개인 QA 식별자를 공개 소스로 복사하지 않았다.

상세 화면은 기존 서버 렌더 함수 안의 선택 필드 조건부 출력이며 새 API·DB·클라이언트 상태·외부 요청·사용자 입력 처리 경로가 없다. notFound, 링크, 저장 대상 ID/title, 기존 샘플·순서·checks·recovery·주의점은 그대로다. 새 section은 같은 수준 h2와 읽을 수 있는 목록을 사용하고 raw HTML 삽입은 없다. 결과 문장이 React의 일반 텍스트로 출력된다.

Guide 타입의 선택 객체와 현재 JSON이 일치한다. 기존 `as unknown as Guide[]` 단언 때문에 앞으로 잘못된 JSON을 넣는 것까지 타입만으로 방지되지는 않지만, 이번 추가 값은 실제 파싱·대조했고 이 변경에서 새로 생긴 실행 오류는 아니다. literal method가 현재 agent-ui 하나이므로 화면의 고정 에이전트 표현과 모순도 없다.
