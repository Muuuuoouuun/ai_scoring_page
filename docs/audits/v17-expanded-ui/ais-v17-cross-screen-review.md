## 캡처 수신 후 기록 형식

각 묶음마다 원본을 `view_image(detail:"original")`로 직접 열고 다음을 남긴다: 정확한 파일명, root가 기록한 URL/환경/viewport와 원본 실제 크기, 실제 읽은 상·중·하/좌·우 범위, 대응 D/M 및 기존 화면과의 1–3문장 비평, 아직 화면 밖이거나 작아서 읽지 못한 부분. 파일 확장자와 원시 이미지 형식이 달라도 원본을 수정하지 않고 실제 판독 가능 여부를 기준으로 한다.

읽기 전에 root의 측정값을 시각 결과라고 확정하지 않는다. 캡처 오류/미로딩/겹침으로 핵심 내용이 읽히지 않으면 해당 파일과 영역을 정확히 거절하고 필요한 보완 구간만 전달한다. 이 초기 절의 대기 상태는 아래 묶음별 기록으로 갱신한다. 일부 묶음만 읽어 **전체 3.4.4 PASS 또는 전체 시각 결함 없음이라는 결론을 내리지 않는다.**
