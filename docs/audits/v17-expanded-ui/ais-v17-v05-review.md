## 우선 보완점

**모바일 청구표의 상태 배지 줄바꿈을 우선 보완해야 한다.** `v05-billing-M-right.jpg`에서 ‘예정 · 미연결’이 ‘예 / 정 / · / 미 / 연 / 결’에 가깝게 한 글자 단위로 쌓인다. 좌·우 사진의 큰 행 높이와 월별 표 사진 위쪽에서도 같은 모양을 확인했다. 가로 스크롤로 해당 열에 도달하는 기능은 확인 범위에 있지만, 도달한 내용의 가독성에는 이 문제가 남는다. 상태·금액 열의 충분한 내부 폭 또는 상태 배지의 줄바꿈 제한을 검토하고, 수정 후 같은 우측 끝 viewport를 다시 확인하는 것이 적절하다. 이 보고서는 CSS 원인을 소스 확인 없이 특정하지 않는다.

이는 과거 긴 full-page 캡처 전체가 한 줄로 붕괴한 캡처 실패와 다르다. 이번에는 정상적인 모바일 viewport 사진에서 **특정 청구표 상태 배지만** 세로로 늘어지며 주변 글자·카드·월별 표는 정상이다. 따라서 캡처 실패로 제외할 근거가 없다.

낮은 우선순위로, 긴 구독명이 많은 폭을 차지하고 좁은 날짜·금액 열의 줄 수를 늘리는 점을 조정할 수 있다. 월별 표는 읽을 수 있으나 우측 끝에서는 월이 보이지 않으므로 반복 비교의 부담이 남는다. 날짜/월을 고정하는 방식이 필요한지는 실제 작업 흐름 관찰로 판단할 수 있으며, 이 사진만으로 필수 요건으로 확정하지 않는다.

## 확인된 범위와 남은 범위

월별 합계와 세 개인 카드의 금액·설명은 데스크톱 및 모바일 연속 사진에서 읽혔다. ‘확인된 금액 없음’과 숫자 0을 섞지 않는 표시, 실제/예상/합계의 구별도 관찰했다. 모바일 청구표는 의도된 스크롤 접근과 별도로 상태 배지 가독성 보완이 남는다.

저장·실제 청구 연결·계산 엔진·실제 개인 부담의 정확성, 반응형 모든 폭, 브라우저 확대, 키보드 스크롤, OS 스크린리더, 실기기 사용성, 실사용자 이해도는 검증하지 않았다. 하단 환불 기록의 전체 카드 및 그 뒤 영역은 이 7장의 범위를 넘으므로 완전 검토했다고 주장하지 않는다. 고정 게이트나 점수는 변경하지 않았다.
