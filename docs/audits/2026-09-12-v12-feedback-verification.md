## 실제 기능과 경계

화면 하단에서 선택적으로 정보 의견을 열고, 로그인한 마이페이지에서는 개인 관리 의견을 연다. 다섯 답변을 구분하고 선택 의견은1,000자로 제한한다. 운영자 열람·시작 기록 수집·민감 정보 미입력 안내를 제출 전에 표시한다. 비회원은 탭의 난수 토큰을 보유하는 동안 해당 의견을 수정·삭제할 수 있고, 로그인 의견은 계정 내보내기와 전체 삭제에 포함된다.

서버가 현재 계정을 확인하고 토큰+계정을 SHA256으로 해시한다. 원본 토큰·검색어·전체 URL·개인 기록 내용은 DB에 자동 저장하지 않는다. 같은 토큰/계정/영역/질문 버전의 재열기는 시작 시각을 유지하고 수정은 최신 응답을 대체한다. 다른 계정·비회원·영역의 응답은 분리한다.

관리자 집계는 현재 질문 버전의 직전30일 UTC **시작 코호트**다. 두 영역과 비회원/로그인 경로의 시작·응답·미응답을 분리한다. 도움 됨 비율의 분모는 도움 됨+일부 도움+도움 안 됨이고, 아직 미사용·판단 어려움은 별도다. 판단 가능한 응답0건은0%가 아니라—다. 삭제한 시작/응답은 집계에서 함께 제거된다. 고유 인원·전체 방문자 만족도·개인 기능 사용/재사용·실제 성과의 측정값이 아니다.

## 실제 브라우저 관찰

로컬 localhost의 명시적 QA 입력으로 정보 의견 일부 도움 저장→닫기→재열기→판단 어려움과 의견 수정→삭제를 수행했다. 개인 영역은 ‘아직 이용하지 않음’으로 저장했다. 관리자에서 정보0/개인 시작1·응답1·판단 가능0·비율—, 로그인 응답1/비회원0을 관찰했다. 이후 개인 QA 의견을 삭제하고 로그아웃하여 비회원의 빈 의견·복구 안내·저장·삭제를 확인했다. 이번에 만든 로컬 의견은 정리했다. 이전 다른 기능의 QA 기록은 건드리지 않았다.

의도적으로 로컬 서버를 중단한 뒤 저장하자 연결 오류가 표시되고 선택·입력 문장이 유지됐다. 당시 기본 브라우저 오류가 영어로 표시되어 최종 소스에서 한국어 복구 안내로 바꿨으며 독립 소스 추출 검사로 확인했다. 개발 서버 재시작의 HMR 새로고침을 넘어 미저장 초안이 유지된다고 주장하지 않는다. 새로고침 간 미저장 의견 초안 보존은 이번 설계에 없다.

저장 중 disabled 버튼에서 초점이 body로 빠지는 실제 문제를 발견해 성공 status·오류·삭제 확인으로 초점을 이동하도록 수정했다. 보완 후 저장 완료 안내가 실제 activeElement이며, 닫기에서 Shift+Tab은 마지막 삭제 버튼으로, Escape는 진입 버튼으로 돌아왔다. 페이지 진입 직후 초기 effect가 열린 창을 지울 여지도 제거했다. 마지막 로컬 정보/개인/비회원 진입은 정상 동작했다.

390px 의견 폼과320px 비회원 모달/관리자 확장 화면,1280px 관리자 배치를 관찰했다.390px에서 문서 가로 넘침 없음,320px viewport에서 문서 scrollWidth305/모달281px이었다. 긴 모달·관리자 내용은 세로 스크롤한다. [캡처 폴더](v12-screens/)의 이미지는 실제 viewport 캡처이며 전체 내용을 한 이미지에 담았다는 의미가 아니다. CSS viewport 지정값과 도구가 반환한 이미지 픽셀 크기는 다르며, 원본 크기(예:390px 설정의375×812)는 manifest.json에 그대로 기록했다. Mac 잠금으로 실제 OS 확대·VoiceOver 실험은 수행하지 않았다.

로컬 관리자 UI만 검증하기 위해 임시 `.dev.vars`에 테스트 계정 권한을 지정했고, 검증 뒤 그 파일 내용이 정확히 임시 설정인지 확인 후 제거했다. 운영 권한/환경에는 손대지 않았다. 로컬 개발 중 아직 migration 적용 전503과 HMR의 기존 다중 렌더러 경고가 있었으며, migration 적용 후 API와 화면이 회복됐다. 이를 운영 오류로 혼동하지 않는다.

## 배포 관찰

운영 관리자 페이지의 정보/개인 두 영역 모두 시작0·응답0·판단 가능0·비율—이며 최근 응답 없음이 표시됐다. 이 조회는 새 DB migration과 관리자 읽기 경로가 배포에서 작동함을 확인한다. 마이페이지의 개인 의견 진입 버튼과 홈의 정보 의견 진입 버튼의 노출만 확인했다. 운영에서는 모달을 열지 않았다. **배포에서는 QA 시작이나 의견을 제출하지 않았다.** 저장·삭제 검증은 로컬 및 실제 API 메모리 DB에 한정한다.

새 운영 관리자/마이페이지 탭과 갱신된 홈 탭의 콘솔 오류0, 최근15분 Worker 오류 이벤트0. 임시 검증 탭을 닫고 화면 크기를 복원했다. 기존 Site 결과 탭을 홈으로 갱신·유지했으며 open_in_codex는 queued를 반환했다. 즉시 전경에 표시됐다는 주장은 하지 않는다.
