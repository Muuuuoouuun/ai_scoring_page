## 3.1.4: 전체 테마 비평으로 인정할 이유

소스의 색상 토큰만 제시하던 V9와 달리, 홈의 옅은 노랑/파란 검색 CTA·공개 카드/문서/표·개인 메뉴/폼/모달/결과·실제 운영 화면을 가로지르는 비평이 있다. 큰 제목과 보조 메타정보, 주/보조/파괴적 행동의 차이, 차분한 어조, 카드/목록의 빈 공간과 반복 밀도, 작은 기능 조건과 추천 근거의 읽기 부담까지 구체적으로 기록했다. 공개 정보가 먼저 드러나는 홈과 독립된 개인 영역의 인상도 v0.6 방향과 연결되어 있다.

긍정 표현만으로 채운 문서도 아니다. 긴 검색어·앵커 가림·필터 빈 안내·행 버튼 폭·203자 자동 제목·모바일 제목/뉴스 폭·로고 캡처·조건 모달 내부 가로 넘침을 구체적으로 구분했고, 고쳐진 부분과 미확인을 분리했다. **이 게이트는 비평을 수행했는지 묻는 문구이지 모든 디자인 선택이 완벽하고 모든 이슈가 사라졌는지를 묻는 문구가 아니다.** 실제 남은 가독성 개선 후보 때문에 비평 수행 근거를 지우거나, 반대로 비평이 있으니 전체 디자인 결함이 없다고 주장하지 않는다.

이 항목들은 ‘주 화면에 들어가 위계를 확인했다’는 근거를 무효화하지 않지만 **확장 화면의 완전한 상호 비교**라는 3.4.4의 요구에는 직접 관련된 공백이다. 다른 게이트에 같은 미확인을 기계적으로 중복 적용하지 않고 원문에 맞는 범위로 판단했다.

### 5.1.4 / 5.2.4 — 별도 실행 없음

실제 200% 확대와 전체 reflow matrix, 실제 스크린리더의 읽기 순서/설명/상태 알림 실행은 수행되지 않았다. 320px·390px 화면, 문서 client=scroll, 보이는 파란 초점, 코드의 ARIA·native dialog는 이를 대신하지 못한다. guest 마이페이지·404/error·모든 펼친/데이터 상태까지 전체 화면 매트릭스 완료를 선언하지도 않는다.

## 출처·환경 적용 한계

이번 결론은 **명시된 V10 로컬 시각 QA + 별도 당시 배포 관리자 정적 관찰**의 충족 근거다. 현재 root의 새 빌드/배포 성공을 확인한 보고서가 아니다. 최종 점수표에는 실제 적용한 소스·배포 식별자와 이 증거의 환경/시각을 연결하고, 이전 배포 관리자 화면이나 이전 수정 전 PNG를 새 배포의 직접 관찰이라고 재표기해서는 안 된다.

사전 계획의 주 화면 위계/테마 비평을 인정하는 것과 모든 상세 상태·접근성·실사용 성과를 인정하는 것은 다르다. 본 결론은 두 시각 관찰 게이트의 근거만 다루며, 원래 152개 게이트의 다른 문구·가중치·판정을 바꾸거나 전체 목표 완료를 선언하지 않는다.
