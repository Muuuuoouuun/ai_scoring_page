# V12 실제 화면 캡처

로컬 및 배포의 원본 viewport 캡처다. 편집·합성하지 않았다. 긴 모달/관리자 내용은 세로 스크롤되며 한 장이 전체 콘텐츠를 포함하지 않는다. `network-error-input-retained.jpg`는 초기 영어 오류가 표시된 관찰이며, 이후 한국어 TypeError 안내로 수정했다. 로컬 서버 재시작/HMR을 넘어 미저장 초안을 보존하는 증거가 아니다.

`admin-320-expanded.jpg`의 개인 세부 집계 펼침은 AX로 확인했으며 이미지 아래쪽 스크롤 밖에 일부 위치한다. 운영 이미지는 의견을 제출하지 않고 빈 집계/진입만 관찰했다. `production-admin-observation.txt`는 운영 집계 영역의 실제 DOM 텍스트다. 이미지 파일 해시·크기는 `manifest.json`에 있다.
