## 왜5.1.4를 제안하고5.2.4는 유지하는가

고정5.1.4는 확대/reflow와 전체 기존 screen matrix의 **측정**이다. 기존28개 주 화면을 한 화면으로 축소하지 않았고, 확인 가능한 현재 중요한 서로 다른 입력·표·결과 몸체의 말단까지 직접 관찰했다. 이미지와 분리된 폭 수치, 실제 확대, 키보드로 내부 표 양끝/공통 모달/하단 제어에 도달한 root 실행이 함께 있다. 확인 중 발견한 실제 긴 선택값 문제와 불완전 로딩·연결환불·toast 캡처를 수정/재촬영했다. 원래의 없는 데이터/같은 구조 변형 한계 조항을 유지한 상태에서 새 필수 몸체의 판독 공백은 남아 있지 않다.
