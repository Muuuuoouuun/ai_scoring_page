- **P03-loaded-01~06 전부:** 01의 검색어 Notion·검색 버튼·“전체3 / 도구1 / 가이드1 / 소식·업데이트1 / 행사0 / 커뮤니티0 / 비교 콘텐츠0” 탭이 온전히 보인다.02에서 같은 탭·“Notion · 3개 결과”·관련도순과 첫 도구 영역을 확인했고,03–06에서 Notion 도구/해당 가이드/업데이트의 각 1개와 설명·이동 링크·푸터까지 다시 읽었다. 최종 데이터가 적용된 상단·요약·모든 결과를 연결할 수 있어 기존 P03 공백이 해소됐다. 새 겹침/가로 클리핑/잘못된 로딩 표시는 보이지 않는다.
- **P07-loaded-01~03 전부:** 01의 제목·최근 7일·후기 참여자 수 기준과 “집계할 공개 후기가 없습니다.”를 읽었다.02는 빈 카드의 **제목·고유 계정 집계 설명·커뮤니티 보기 CTA 전체**와 아래 성능순위아님 안내를 한 화면에 담고,03은 안내와 푸터를 담는다. 이전 헤더에 가려졌던 빈 상태 제목이 이제 실제로 판독되어 기존 P07 공백이 해소됐다. 표가 없는 것은 명시된 공개 후기 0건 상태이며 렌더 실패로 세지 않는다.

9장의 실제 래스터는 모두 953×395이고, 두 JSON의 모든 항목은 CSS 960×398/DPR2 및 clientWidth=docWidth=952다. 검색은 처음부터 끝까지 scrollHeight 1286, scrollY 0→199→398→597→796→888이며 마지막 잔여 높이 0이다. 랭킹은 처음부터 789, scrollY 0→199→391이고 마지막 잔여 높이 0이다. 초기 묶음과 달리 캡처 도중 문서 높이 변화가 없으며, 각 실제 마지막 이미지에도 푸터가 보인다.

추가 직접 연 파일: `P03-loaded-01.jpg`, `P03-loaded-02.jpg`, `P03-loaded-03.jpg`, `P03-loaded-04.jpg`, `P03-loaded-05.jpg`, `P03-loaded-06.jpg`, `P07-loaded-01.jpg`, `P07-loaded-02.jpg`, `P07-loaded-03.jpg`; 대응 `P03-loaded.json`, `P07-loaded.json`.

**현재 누적 90장 모두 판독, 요청한 두 보완은 완료.** 기존 P01–P09 공개 principal의 이 캡처 범위에서 남은 캡처 공백이나 새 중대 시각 결함을 찾지 못했다. 열지 않은 공통 메뉴·필터/다른 결과·폼·실제 키보드 초점 및 스크린리더 관측은 앞서 구분한 별도 범위 그대로이며, 이 보완이 전체 28 principal/확장 matrix나 5.1.4/5.2.4를 자동 PASS로 바꾸지는 않는다.
