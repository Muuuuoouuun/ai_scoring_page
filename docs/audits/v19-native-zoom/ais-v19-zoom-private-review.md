# Native Chrome 200% 독립 시각 검토 — A01, M01~M07 및 확장 상태

검토일: 2026-09-14. 읽기 전용 검토이며 UI·코드·배포·데이터·점수를 변경하지 않았다. 개인 식별자와 개인 기록 본문은 옮기지 않았다.

## 범위와 근거

초기 64장, 첫 확장 41장, 로컬 기록 및 조건 이력 43장, 결제·해지 및 비교 확장 43장, 변경 비교 확장 45장, 오른끝·환불·결과 분기 보완 44장, 긴 선택값 수정 후·커뮤니티·기존 편집 53장, 마지막 화면 크기·평가 필터·새 구독 상세 16장을 더해 JPG 총 349장과 캡처 JSON 총 55개를 검토했다. 추가로 fixture 영수증 JSON 2개를 읽었다. 349장에는 목표 필드가 보이지 않는 초기 S09-linked-refund 1장이 포함되어 있으며 해당 상태의 유효 증거로 인정하지 않는다. 후속 visible 이미지에서 목표를 확인했다. 프레임 수는 통과 상태 수가 아니다.

- 제공된 `docs/audits/v19-native-zoom`의 JPG 64장을 각각 `view_image`로 직접 판독했다: A01 기본 12장, A01-details-expanded 15장, M01 4장, M02 4장, M03 4장, M04 5장, M05 5장, M06 5장, M07 10장.
- 대응 JSON 9개 전체를 읽고 프레임 수·순서·도달 범위·파일 존재·화면 치수를 확인했다.
- 초기 64장 프레임은 CSS viewport 960×398, DPR 2, clientWidth/docWidth 952/952로 일치한다. `actual-chrome-200.txt`의 Native Chrome 확대/축소 200% 기록도 확인했다. 배포 소스 동일성은 이 독립 검토에서 다시 검증하지 않았다. 마지막 보완에는 별도 100% 데스크톱 및 390px 화면도 포함되므로 전체 349장을 모두 200% 증거로 표현하지 않는다.
- 초기 A01/M01~M07 모든 시퀀스는 scrollY 0부터 시작해 약 199px 간격으로 겹치며, 마지막 viewport가 문서 끝에 도달한다. 상단 고정 내비게이션 아래로 지나가며 일부 내용이 가려진 프레임은 앞뒤 겹치는 프레임에서 확인했다.

## 판독 결과

현재 64장에 보이는 상태에서 수정이 필요하다고 확정할 수 있는 가로 잘림, 컨트롤 충돌, 읽을 수 없는 줄 겹침, 운영 표 오른쪽 끝 열 누락은 발견하지 못했다. 이는 해당 화면 상태와 크기에 한정된 결과이며 전체 접근성 완료나 미노출 상태 통과 판정이 아니다.

## 확장 상태 추가 검토

추가 JPG 41장을 각각 `view_image`로 직접 판독했고 JSON 7개 전체를 확인했다. 이미지 전용 증거 `S02-modal-focus-wrap.jpg`에는 대응 JSON이 없다. 추가 화면 모두 CSS viewport 960×398 / DPR 2로 촬영된 자료다. 모달의 외곽은 x 약 166 / y 약 20 / 폭 620 / 높이 약 358이고 내부 clientWidth와 scrollWidth는 613/613으로 일치한다. 추가된 일반 페이지 프레임도 clientWidth/docWidth 952/952로 일치한다.

주검사자가 실제 키보드로 확인했다고 전달한 결과는 다음과 같다: 저장하기에서 Tab을 누르면 닫기로 순환하고 modalTop이 0으로 돌아오며 닫기 버튼이 viewport 안에 있음, Escape 후 모달이 없어지고 원래 구독 추가 버튼으로 포커스 복귀. 이 독립 검토자는 S02 이미지의 닫기 포커스를 직접 확인했으며, 키 입력과 Escape 전후 동작 자체는 주검사자의 실행 보고에 근거한다. 실제 저장이나 데이터 삭제는 실행하지 않았다고 전달받았다.

`S11-delete-review`라는 모달 캡처 시도는 삭제 안내가 인라인 폼이어서 실패했다고 전달받았다. 해당 파일은 존재하지 않으며 성공한 증거로 계산하지 않는다. 대신 존재하는 `S11-delete-inline-01~03`만 직접 판독하고 세었다.

## 보완 검증이 필요한 상태

이 목록은 뒤의 모든 확장 검토를 반영한 현재 잔여 범위다.

1. **긴 선택값 보완 완료:** 초기 S08 닫힌 선택창에서 긴 구독명의 끝이 보이지 않던 제한은 S08-fixed 네 시퀀스의 선택창 아래 전체 이름·요금제·다음 결제일 안내로 해소했다. S09 비교 화면에는 기존 시퀀스에서도 선택 구독의 긴 이름을 감싸는 안내문이 보였다. 단일 행 편집 입력의 가로 이동과 화면 낭독 연결 자체는 정지 이미지로 검증하지 않았으며, 이 일반적 기능 미검증을 별도의 확정 시각 결함으로 기록하지 않는다.
2. **해소된 증거 누락:** S09-linked-refund는 푸터만 보여 최초에는 실패한 목표 캡처로 기록했다. 후속 S09-linked-refund-visible에서 실제 필드를 확인해 이 누락을 해소했다. 내부 표 오른끝도 후속 단일 4장·연속 10장과 scrollLeft 수치로 해소했다. 전환 비용 중첩 상세와 계산 결과, 실제 구독 변경 비교의 펼친 필드와 저장한 비교도 확인했다.
3. **설정 저장·폼 오류:** 혜택 조건·자격과 예산의 펼친 필드 및 구독 충돌 경고는 확인했다. 설정 저장 결과와 모든 폼의 검증 오류는 확인하지 않았다. 삭제 실행 결과는 검토하지 않았고 실행할 필요도 없다.
4. **미노출 기록 종류:** M02 저장 콘텐츠, M05의 비어 있지 않은 해지 기록 목록, M06 알림, A01 최근 응답은 빈 상태만 검토했다. 결제·환불 행과 구독·비교의 긴 이름은 기존 로컬 QA 기록으로 확인했으나 모든 운영 데이터의 모양을 보증하지 않는다.
5. **로딩 후 상태:** 이 세트에 로딩 스피너만 남은 캡처는 보이지 않는다. 다만 M06의 이메일 연결 준비 중 안내는 후속 전송·완료·오류 상태의 증거가 아니므로 관련 동작 성공이나 로딩 후 전체 흐름 검증 완료로 계산하면 안 된다.
6. **키보드와 더 좁은 폭:** 일부 포커스 외곽선 및 주검사자가 보고한 구독 모달 순환·복귀를 확인했다. 모든 조작의 키보드 도달, 화면 낭독 순서, 400% 확대나 더 좁은 viewport는 이 결과 범위 밖이다.

## 로컬 기록과 조건 이력 추가 검토

`M03-local-expanded` 17장, `S07-history` 3장, `S07-correction-expanded` 8장, `S07-new-variable-fields` 9장, `S07-preview-conflict` 2장, `S07-preview-normal` 4장 — JPG 43장 모두 직접 판독하고 대응 JSON 6개를 확인했다. 주검사자는 기존 로컬 QA 데이터 7행을 바꾸지 않고 폼과 미리보기만 열었다고 보고했다. 이 검토자는 UI·소스·데이터를 변경하지 않았다.

- **긴 기록 및 표:** M03의 긴 구독명은 카드와 예정 청구 표의 이름 열 안에서 여러 줄로 줄바꿈된다. 오른쪽의 조건 이력·수정·삭제 버튼과 결제 확인 상태가 가려지지 않는다. 예정 청구 표와 펼친 월별 표는 첫 열과 마지막 열이 모두 보이고, 뒤이어 개인 부담 카드와 긴 이름의 실제 결제·환불 기록이 끝까지 보인다. 근거: M03-local-expanded-03~17.
- **조건 이력:** 긴 이름이 들어간 설명, 이력 두 항목, 변경 조건 추가·정정·철회 버튼이 모달 폭 안에 들어온다. 모달 상단과 바닥을 모두 확인했다. 근거: S07-history-01~03.
- **정정 폼:** 날짜·금액·통화·주기·상태와 펼친 좌석·세금·부담액, 변경 이유 및 메모, 안내와 하단 미리보기/저장 버튼이 정상 배치된다. 이 시퀀스는 scrollTop 56.5부터 시작하므로 정정 상태의 제목·닫기 버튼 자체는 독립적으로 촬영되지 않았다. 필드 본문부터 끝까지는 연속적으로 보인다. 근거: S07-correction-expanded-01~08.
- **가변 필드:** 새 조건의 월 간격, 일시중지 상태에 따른 청구·재개일 필드, 펼친 좌석·세금 영역, 사유 입력과 하단 버튼까지 보인다. 위·아래를 겹치는 모달 스크롤로 도달했고 필드가 가로로 겹치거나 잘리지 않는다. 근거: S07-new-variable-fields-01~09.
- **충돌 경고:** 결과 영역 안의 경고가 여러 줄로 읽히고 카드 내부에 유지된다. 경고 자체를 레이아웃 실패로 간주하지 않는다. 근거: S07-preview-conflict-02.
