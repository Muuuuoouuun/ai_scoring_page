# V11 검색·추천 개선과 배포 검증

2026-09-12. 참고 이미지의 아이보리·코발트·옅은 노랑 톤과 기존 정보 중심 구조를 유지했다. 화면 복제나 기능 축소 없이, 등록된 기능과 실제 업무 문장을 연결하는 검색 및 추천 근거를 개선했다.

## 적용 내용

- 전체 문장 부분 일치와 제품별 키워드 가산점을 일반 업무 어휘·직접 기능·활용 예시의 관련성 계산으로 교체했다. 작업 대상과 동작을 함께 보며, 이미지 입력을 이미지 생성으로, 프롬프트 작성을 보고서 작성으로 연결하는 관찰된 오류를 줄였다.
- 명시한 제품·분야·유형·코딩 중심 도구의 제외를 긍정 목적과 분리한다. `말고/빼고/제외/아닌/없이/원하지 않음`을 처리하며, 인식하지 못한 제외 대상은 미적용 사실을 표시한다. 바코드의 코드 부분을 개발 제외로 잡거나, 이중 부정·무료 비필수 조건을 반대로 적용한 반례를 수정했다.
- 무료 플랜과 기능별 무료 범위를 구분한다. 실제 feature의 상태·조건·공식 URL을 그대로 표시한다. 오프라인·기기 내 처리·단계 수 등은 공식 근거만으로 확인되지 않은 요구 조건으로 명시한다. ‘조건 확인 필요’는 미지원 단정도, 충족 보장도 아니다.
- 도구함 범위는 현재 Provider 사용자 객체와 요청 생명주기에 묶는다. 불러오기·실패·재시도 중 전체 목록으로 범위를 넓히지 않는다. 기존 종류·분야·무료·한국어·owned 교집합과 공개 검색의 개인정보 제외를 보존했다.
- 기존 일반 링크와 비교 선택을 재사용한다. 새 외부 서비스 호출이나 의존성, 카탈로그 사실·기능·요금 수정은 없다.

## 남은 한계와 점수 범위

하위 순위의 부분 관련 후보는 남는다. 예: SNS 목적에 Vercel, 일부 이미지 요청에서 이미지 입력 모델이나 문서 후보. 영어 부분 문자열과 복합 동작의 방향까지 완전한 문장 이해를 제공하지 않는다. 인식하는 환경·수량 조건도 한정되어 있다. 공식 원문 확인과 조건 안내를 전체 업무 수행 보장으로 승격하지 않는다.

고정6.2.4 원문은 `A varied set of realistic purpose/condition queries has evaluated relevance.`다. 다양한 사전 고정 질의를 실제 평가하고 실패·개선·남은 한계를 기록했으므로 해당 평가 수행 문항만 PASS로 반영한다. 실제 비교 선택 연구·가이드 외부 재현·스크린리더·타 계정 운영 관찰·이메일/무인 운영은 새로 인정하지 않는다.9영역/38세부항목/152게이트와 가중치를 유지한다. 유용성80→86.25, 전체 목표는 여전히 미완료다.
