## 실제 이미지 검토와 환경

[사전 화면 인벤토리](2026-09-12-v10-screen-matrix.md)에 따라20개 경로 템플릿을28개 주 화면으로 펼쳐 D/M을 캡처했다. [고정 게이트 독립 평가](2026-09-12-v10-frozen-gate-assessment.md)의28행 대응표는 각 실제 이미지 판독 보고서와 연결된다. 기본 D1440×900/M390×844이며 scrollbar를 뺀 client1425/375와 구별한다. 일부 추가 관찰은320px이다. 실제200% 브라우저 확대는 수행하지 않았다.

이미지는 [v10-screens](v10-screens/)에 있고 URL·시각·문서 폭은 `observations.jsonl`에 보관했다. `.png` 파일명이나 실제 screenshot bytes는 JPEG/JFIF인 경우가 있다. 그대로 저장한 브라우저 캡처이며 이미지 편집으로 상태를 만들지 않았다. 긴 fullPage 이미지가 검토 도구에서 축소되면 작은 문구를 읽었다고 판정하지 않았다.

- 03은 hydration 이전 검색 결과가 일치하지 않아 제외했다.
- 11/12/46/77은 fullPage 캡처의 잘못된 얇은 세로 재배치다. 유효한 실제 viewport13/87/86과 측정으로 대체하고 제품 오류로 세지 않았다.
- 28/34의 아래쪽 빈 로고는 lazy-loading 캡처와 구분했다. 실제 위치에서94–96을 캡처해 Supabase196px/Vercel256px 원본 로딩과 실제 마크를 확인했다.
- 로컬 QA의 비용·후기·랭킹·개인 기록은 실제 사용자 연구/실제 구독으로 세지 않았다. 현재 배포 관리자59/60과100–104는 운영 환경이고, 그 안의 처리된 신고는 이전 검증용 신고이다.
- 독립 검토자는 각 담당 이미지를 직접 열었다. root가 모든 파일을 다시 열었다고 주장하지 않는다. [최종 수정86–98](2026-09-12-v10-final-repair-review.md), [배포 보완99–104](2026-09-12-v10-production-visual-review.md)를 별도 보관한다.
