# V23 범위와 공식 기능 보완

사용자 결정(2026-09-15): “지금 연결은 하지 않기”. 실제 외부 계정 OAuth 연결·앱 등록·비밀키 설정은 이번 완료 범위에서 제외하고 보류한다. 조사 파일은 참고자료이며 연결 완료를 뜻하지 않는다. 개인 서비스 등록과 공식 카탈로그 정보 연결은 유지한다.

현재 목표 도구는 paused를 반환했다. 대화 요청에 따라 작업을 계속했으나 목표 자동 실행 상태를 재개했다고 주장하지 않는다.

2026-09-15 직접 확인한 문서 작성 기능:
- ChatGPT: https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt — 문서/메일 초안, 직접 편집과 수정 요청. 플랜·기기·설정·모델·계정 제공 상태의 차이 보존. 이전 Canvas 명칭을 현재 기능으로 복제하지 않았다.
- Notion: https://www.notion.com/help/writing-and-editing-basics — 블록 기반 텍스트·제목·목록·표 작성, 서식·순서 편집. 기본 편집과 AI 이용 조건 구분.
- Gemini: https://support.google.com/gemini/answer/16047321?hl=en-NZ — Canvas 문서 작성, 선택 영역 수정, 길이·어조 편집. 로그인과 컴퓨터 웹 기준 명시.

각 서비스의 다른 기능을 전부 다시 검수한 것으로 보이지 않도록 전역 checkedAt은 변경하지 않았다. 위 3개 추가 기능만 이번 날짜에 확인했다.

수정: 문서 작성/요약 요청과 프로젝트 현황 보고서 조회 구분. Canva의 명시적 이미지 편집 설명을 비교 근거로 포함. 비해당 혜택 자격은 개인 화면에 사용자 선택을 표시.
