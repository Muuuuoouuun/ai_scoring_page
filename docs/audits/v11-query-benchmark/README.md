# V11 원본 검증 보관

35개 독립 보고서·실행기·고정 표본·소스 스냅샷을 원래 이름과 바이트 그대로 복사했다. [복사 해시](copy-manifest.json)에 크기·SHA-256을 기록했다. README와 manifest는 원본 개수에서 제외한다.

원본 실행기에는 당시 `/private/tmp` 및 작업 공간의 절대 경로와 기존 결과 덮어쓰기 방지가 있다. 그대로 재실행해 과거 기록을 덮어쓰지 않는다. 새 관찰은 별도 출력 이름/경로를 사용하는 실행기로 수행해야 한다. 과거 결과는 각 `source-snapshot.json`의 실제 소스에 한정된다. 원본 보고서 내부의 임시 경로 링크는 이 디렉터리에 있는 같은 이름의 보관 파일로도 확인할 수 있다.

최종 판정은 `ais-v11-relevance-final-regression-2.json/.md`의36/36이다. 초기32/36, 중간35/36도 함께 보존한다. 최초 비공개16은 공개 후 회귀 표본이며, 후속 통과를 새로운 맹검 표본으로 계산하지 않는다. 전체 검증과 실제 배포 UI는 [V11 검증 기록](../2026-09-12-v11-search-verification.md)을 따른다.
