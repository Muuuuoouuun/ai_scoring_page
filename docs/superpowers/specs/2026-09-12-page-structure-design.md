# AI Score / AIs — 페이지 구조와 아이디어

작성일: 2026-09-12. 페이지 구조 제안과 후속 아이디어를 정리한 문서다. 전체 제품 방향과 출시 기준은 [통합 기획서 v0.6](../../2026-09-12-product-plan-v0.6.md)을 따른다. 실제 화면 구현, 사용자 검증, 개발 일정 확정을 의미하지 않는다.

## 1. 기본 방향

**발견형 홈과 별도의 도구 탐색을 함께 제공한다.** 홈에서 새로운 정보를 발견하고, 도구·활용법·소식·경험을 자세히 알아보며, 필요하면 내 공간에 저장한다. 읽고 이해하는 것만으로도 완결된 이용이며, 저장이나 개인 관리까지 진행할 필요는 없다.

| 검토한 방향 | 장점 | 고려할 점 |
|---|---|---|
| 매거진 중심 | 소식·활용법을 읽으러 가볍게 방문하기 좋음 | 특정 도구를 찾는 동선이 길어질 수 있음 |
| 도구 검색 중심 | 기능 검색과 비교 목적이 명확함 | 읽을거리와 커뮤니티가 부차적으로 보일 수 있음 |
| 발견형 홈 + 별도 도구 탐색 — 채택 방향 | 가벼운 정보 탐색과 구체적인 도구 검색을 모두 수용 | 홈의 편집·발견 역할과 탐색 페이지의 검색·필터 역할을 구분해야 함 |

정보 탐색은 개인 관리와 최소 동등한 비중을 유지한다. 로그인 여부와 관계없이 기본 홈은 공개 정보 탐색 화면으로 열고, 마이페이지는 고객이 선택해 이동하는 개인 공간으로 둔다.

## 2. 상위 메뉴와 페이지 계층

상위 메뉴는 기존 기획의 다섯 개를 유지한다. 아래 페이지 계층은 정보 구조이며, URL과 화면 내 탭 구성은 후속 화면 명세에서 정한다.

| 상위 메뉴 | 하위 페이지·영역 | 고객의 목적과 대표 행동 |
|---|---|---|
| 발견 · 홈 | 주제별 모음, 활용법 목록·상세 | 볼 내용을 정하지 않은 상태에서 주요 정보·도구·활용법을 발견 |
| 도구 탐색 | 도구 검색·목록, 도구 상세, 평가·비교 | 필요한 기능을 찾고 후보들의 차이와 조건을 이해 |
| 소식·행사 | 뉴스, 제품 업데이트, 할인·체험, 행사 목록·상세와 일정 | 변화의 의미와 적용 대상, 참여 기회·조건을 확인 |
| 커뮤니티 | 사용 경험, 질문·답변, 활용 조합, 제작자 소개 | 사람들의 경험을 읽고 질문하거나 의견을 나눔 |
| 마이페이지 | 내 도구함, 저장·활동 기록, 구독·비용, 절약 비교, 해지 관리, 관심 알림·설정 | 개인 기록과 사용 중인 서비스·계약을 관리 |

활용법은 독립된 목록·상세 페이지를 갖고 발견 메뉴와 도구 상세에서 연결한다. 독립 페이지를 모두 상위 메뉴로 올리지는 않는다. 공개 작성·답변 범위는 운영 여력에 맞춰 확장하며, 첫 공개의 커뮤니티 최소 범위는 v0.6의 검수한 경험 열람·질문 접수를 따른다.

공통 검색은 서비스명·기능·목적·알고 싶은 내용을 입력받고, 결과를 도구·비교·활용법·소식·행사·공개 경험으로 구분한다. 도구 탐색에서는 도구 조건에 맞는 필터를 제공하고, 내 도구함 내부 검색은 개인 목록을 검색한다는 범위를 표시한다.

## 3. 홈 구성

| 순서 | 영역 | 내용과 다음 행동 |
|---|---|---|
| 1 | 검색과 짧은 소개 | 검색창과 기능·목적 예시를 제공. 서비스명이나 알고 싶은 내용을 검색 |
| 2 | 오늘 알아볼 것 | 주요 변화·새 도구·추천 글을 소수 선별. 무엇인지와 왜 알아둘 만한지 요약하고 상세로 연결 |
| 3 | 하는 일로 찾아보기 | 자료 조사, 문서 작성, 이미지 제작, 개발 등 목적별 도구·콘텐츠로 진입 |
| 4 | 비교와 활용법 | 같은 작업으로 도구를 비교한 글, 결과부터 보여주는 사용 안내 제공 |
| 5 | 다가오는 행사와 최신 소식 | 일정·마감·신청 조건 또는 변경 적용 조건을 확인하고 상세로 이동 |
| 6 | 사람들의 경험 | 구체적인 사용 후기와 질문을 읽고 관련 도구·토론으로 이동 |

검색 안내 문구 후보는 “어떤 일을 하고 싶으세요?”로 두되, 서비스명이나 소식에 관한 질문도 검색할 수 있음을 함께 안내한다. 작업 목적의 예시는 탐색 진입점이며 전체 정보 범위를 해당 업무로 제한하지 않는다.

로그인 후에도 공개 홈을 유지한다. 내 도구함·저장한 콘텐츠 바로가기를 제공하고, 관심 주제 강조는 선택적인 개인화로 둔다. 소식이 없을 때 새로운 내용이나 인기 순위를 임의로 만들지 않는다.

## 4. 도구 상세

도구 상세는 도구 정보·평가·활용법·변화·사람들의 경험을 연결하는 중심 페이지다. 상단에서 **무슨 도구인지, 누구에게 맞는지, 주요 제약이 무엇인지** 먼저 설명한다.

| 정보 묶음 | 제공할 내용 |
|---|---|
| 개요 | 주요 기능, 결과 예시, 지원 환경, 가격·무료 범위와 확인일 |
| 평가·비교 | 평가한 작업·요금제·버전·평가일, 강점·한계, 비교 후보와 근거 |
| 활용법 | 준비물·가능한 플랜·입력 예시·단계·결과 확인을 갖춘 작업별 안내 |
| 업데이트 | 최근 달라진 기능, 변경 전후, 적용 대상과 제공 상태 |
| 사용자 경험 | 사용 목적·플랜·시점을 알 수 있는 후기와 관련 질문 |

주요 행동은 `공식 사이트`, `비교에 담기`, `저장`이다. 공식 사이트 이동은 외부 도구를 이용하는 경로이며 실제 작업 성공을 의미하지 않는다. 비교 후보를 담고 비교 내용을 읽는 과정은 비회원도 이용한다. 계정에 비교나 콘텐츠를 보관할 때 로그인을 연결한다.

평가하지 않은 도구도 기본 정보를 제공하고, 평가 미실시 상태를 표시한다. 미실시를 0점으로 처리하지 않는다. 발표·제공 상태와 공식 자료 확인·직접 테스트 여부를 구분한다. 비교는 같은 작업과 조건을 이해할 수 있게 구성하며 근거 없는 전체 순위나 개인 적합성 백분율을 만들지 않는다.

## 5. 대표 이용 흐름

| 방문 목적 | 경로 | 성공 상태 |
|---|---|---|
| 새로운 정보 발견 | 홈 → 주요 소식 또는 활용법 상세 → 관련 정보·원문 | 새로운 내용과 의미를 이해함 |
| 필요한 도구 찾기 | 검색 또는 목적별 탐색 → 도구 상세 → 후보 비교 | 기능·조건·차이를 이해함 |
| 작업 방법 배우기 | 활용법 목록 또는 도구 상세 → 결과 예시·단계 → 필요하면 공식 도구 | 방법과 시작 조건을 이해하고, 원하는 경우 직접 시도함 |
| 경험 확인·질문 | 커뮤니티 또는 도구 상세 → 후기·질문 → 질문 접수·참여 | 참고할 경험을 얻거나 자신의 질문을 전달함 |
| 개인 정보 관리 | 마이페이지 → 도구함·저장함·구독 등 해당 영역 | 기록을 다시 찾거나 비용·계약·해지·알림 상태를 관리함 |

개인 관리 이용자는 마이페이지에 바로 진입할 수 있다. 공개 정보를 읽는 고객에게 도구 등록이나 구독 입력을 선행 단계로 요구하지 않는다.

## 6. 공통 상태와 복구

| 상황 | 화면의 대응 |
|---|---|
| 비회원 이용 | 공개 검색·열람·비교를 제공. 계정에 저장, 개인 알림 설정, 글 작성처럼 필요한 행동 시 계정을 연결 |
| 로그인 연결 | 진행하던 화면과 저장 대상 등 행동 맥락을 보존하고 인증 후 이어갈 수 있게 함 |
| 검색 결과 없음 | 적용된 조건을 보여주고 조건 수정·관련 주제 탐색을 제공. 필수 조건을 몰래 완화하지 않음 |
| 빈 저장함·내 도구함 | 공개 콘텐츠 탐색이나 첫 항목 추가 경로를 제공 |
| 평가·경험 없음 | 평가 미실시 또는 등록된 경험 없음으로 표시하고 확인된 기본 정보·활용법으로 연결 |
| 종료된 행사·프로모션 | 종료 상태와 날짜를 표시하고 진행 중인 기회로 안내하지 않음 |
| 정보 로딩·저장 실패 | 오류와 재시도 경로를 제공하고 입력·선택을 보존. 저장 실패를 저장 완료로 표시하지 않음 |
| 개인 기록 공개 | 비용·메모·계약은 기본 비공개. 공유할 때 공개 범위를 별도로 선택하고 확인 |

## 7. 아이디어와 적용 순서

다음은 이번 페이지 기획에서 제안한 아이디어의 우선순위다. 별도 기능 전체의 출시 확정이나 기존 v0.6 범위 축소를 뜻하지 않는다.

| 아이디어 | 고객 경험 | 적용 시점 제안·조건 |
|---|---|---|
| 무엇이 달라졌나요? | 업데이트를 ‘이전 → 변경 → 해당 사용자’로 요약 | 초기. 변경 내용·대상·출처·확인일을 검수한 범위 |
| 결과부터 보는 활용법 | 완성 예시를 먼저 보고 준비물·단계를 펼쳐봄 | 초기. 재현 가능한 안내와 결과 예시를 확보한 범위 |
| 같은 작업, 다른 도구 | 동일한 입력과 조건으로 결과·비용·수정 부담을 비교 | 초기. 직접 검증한 작업·플랜·버전 범위 |
| 상황별 도구 모음 | 회의 후 정리, 논문 읽기처럼 작업 상황별로 탐색 | 초기. 도구를 묶은 이유와 각각의 역할·제약을 설명 |
| 도구 조합 안내 | 한 도구의 결과를 다음 도구에 넘기는 방법을 설명 | 후속 확장. 자동 연동과 수동 복사·내보내기를 구분하고 조합을 검증 |
| 내 도구로도 가능한가요? | 검색에 선택적으로 내 도구를 반영해 기존 도구의 활용법을 발견 | 후속 확장. 현재 질문의 조건을 우선하고 기능·플랜 근거를 확인 |

도구 조합 안내와 내 도구 반영의 기본 개념은 v0.6에 포함되어 있다. 위 후속 분류는 별도의 강조 화면·정교한 연결 경험을 발전시킬 순서이며, 기존의 검수한 활용법이나 선택적 개인화 방향을 폐기하는 의미가 아니다.

## 8. 후속 화면 명세와 검토 기준

화면 명세는 **정보 중심 홈 → 도구 탐색·검색·상세·평가/비교 → 소식·행사·활용/경험 → 마이페이지** 순서로 구체화한다. 이는 설계 작업 순서이며 개인 관리 기능의 첫 공개를 미루는 출시 순서가 아니다. 두 축의 첫 공개 기준은 v0.6을 유지한다.

각 화면은 고객 목표, 대표 행동, 성공 상태, 빈 상태, 오류 복구, 다음 행동을 같은 양식으로 정의한다. 공개 정보만 이용하는 경로와 개인 관리 경로를 각각 검토하고, 가입·저장 여부와 별도로 정보 이해를 확인한다. 구현 이후 검증에는 비회원 검색·비교, 로그인 후 행동 이어가기, 오류 재시도, 평가 미실시 표시, 종료 행사 상태, 개인 기록 공개 범위를 포함한다.
