# 서비스 확충과 개인 서비스 연결

최신 사용자 목표(2026-09-15)는 AI/SaaS/모델·협업/PMS 카탈로그 확충, 실제 로고/기능/업데이트, 사용자 평가·기능·후기 입력, 디자인 보완, 내 서비스 등록·연동 및 유사 기능/프로모션 발견이다. 기존 전체 개발·배포 승인을 따른다. 이전 88점 평가표는 역사 기록으로 보존하며 이번 목표를 메일 설정 대기로 축소하지 않는다.

정보 중심 홈과 아이보리·코발트·노랑의 절제된 톤을 유지한다. 내 도구함에서 등록 서비스별 구독 기록·공식 최신 정보·공통 기능을 가진 대안·관련 혜택을 한 흐름으로 연결한다. 계정 연결(OAuth/API)과 카탈로그 정보 연결을 동일하게 표시하지 않는다. 계정 연동의 우선 범위는 사용자에게 질문했으며 외부 데이터 접근을 임의로 완료했다고 표시하지 않는다.

기존20개에 없는 AI6개, SaaS/협업/PMS8개를 공식 출처 조사 후 추가한다. 날짜가 확인되지 않은 업데이트는 날짜 미확인으로 표시한다. 실제 제품 아이콘을 보존하며 모델은 공급자 로고 사용을 명시한다. 새로운 업무 분류는 탐색·검색에서 같은 의미를 갖게 한다.

비슷한 도구는 같은 카테고리라는 이유만으로 추천하지 않는다. 양쪽의 지원/조건부 기능에서 확인되는 같은 작업을 연결하고 각 기능·이용 조건·원문을 제시한다. 모델과 완성 앱의 이용 형태는 구분한다. 공통 기능이 없으면 결과가 없다. 점수·품질 우위를 추정하지 않는다.

사용자가 직접 입력한 서비스는 이름·공식 사이트의 정확한 일치로 카탈로그 연결 후보를 제시할 수 있다. 기존 사용자 입력은 자동으로 덮어쓰지 않으며 선택 후 연결한다. 다른 소유자의 기록, 동일 서비스 중복과 기존 계정 저장 경계를 API에서 유지한다. 외부 서비스의 구독·결제 상태를 실제 API 없이 자동 수집한 것으로 표시하지 않는다.

공식 학생/교육/스타트업 지원 프로그램을 검증해 혜택 범위를 늘린다. 상시 프로그램은 없는 마감일을 만들지 않는다. 상시 모집과 마감 미확인을 구분하고, 공식 조건의 확인 기간이 지난 자료는 재검토 상태로 둔다. 자격·요금·갱신 조건과 사용자 확인은 기존 보류 규칙을 유지한다. 프로모션 페이지의 특정 국가/학생용 고정 문구를 각 혜택의 사실로 바꾼다.

검증은 추천의 공통 기능/조건/없음/모델 경계, 서비스 연결의 중복·소유권·원본 보존, 마감 날짜와 상시 프로그램/오래된 조건, 기존 알림·수신 동의·이메일 보류 회귀다. 실제 브라우저에서 새 서비스 찾기→등록→정보/대안/혜택, 사용자 기능 제안/평가 진입, 모바일 배치를 확인한다. 독립 검토·타입/빌드 이후 기존 비공개 Sites에 배포한다.
