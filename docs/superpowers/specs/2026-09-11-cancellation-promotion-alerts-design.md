**AI Score / AIs — 해지 길잡이·관심 프로모션 알림 상세 기획**

작성일: 2026-09-11. [통합 기획서 v0.6](/Users/bigmac_moon/dev/ai_score/docs/2026-09-12-product-plan-v0.6.md)에 포함된 해지·개인 알림 기능의 설계안이다. 고객의 실제 구독 해지, 행사 감시, 이메일 발송을 설정한 문서가 아니다. 기존 비용 계산은 [구독 비용 상세 기획](/Users/bigmac_moon/dev/ai_score/docs/superpowers/specs/2026-09-11-subscription-optimization-design.md)을 따른다.

2026-09-12 정합성 반영: 이 문서는 구독·해지·개인 알림에 관한 개별 기능 명세다. 전체 서비스는 AI·SaaS 정보·평가·추천·소식·행사·커뮤니티에 최소 동등한 비중을 두며, 기본 홈은 공개 정보 탐색이다. 전체 우선순위와 출시 기준은 통합 기획서 v0.6을 따른다. 공개 해지 안내와 행사 정보는 개인 기록 없이도 이용할 수 있다.

**고객 가치 — 해지할 때의 막힘을 줄이고, 관심 있는 기회를 다시 검색하는 수고를 줄인다.**

해지 방법은 필요할 때 바로 찾는 도움이고, 프로모션 알림은 고객이 관심 조건을 맡겨두는 기능이다. 내 서비스·사용 목적·구독 조건을 공유하되, 해지 안내를 보기 전에 할인·대체재 제안을 거치게 하지 않는다. 해지와 구매 모두 고객이 자신의 조건을 이해하고 선택하도록 돕는다.

**해지 길잡이의 입구 — 구독 카드와 검색에서 바로 연다.**

내 구독 카드에는 ‘해지 방법 보기’를 제공한다. 공통 검색에서 ‘서비스명 해지’, ‘다음 결제 막는 방법’으로도 찾을 수 있게 한다. 도구를 저장하지 않은 고객도 일반 안내를 볼 수 있다. 사용 중단·내 목록에서 제거·서비스 구독 해지·계정 삭제의 의미와 행동을 구분한다.

해지 방법은 결제한 경로에 맞춰 보여준다. 구독 기록에 청구처가 있으면 이를 사용하되 고객이 수정할 수 있게 한다. 저장된 정보가 없으면 ‘서비스 홈페이지 / Apple / Google Play / 다른 판매처 / 잘 모르겠어요’ 중 선택하도록 안내한다. 현재 기기와 실제 결제 경로가 같다고 가정하지 않는다.

Apple은 구독을 찾지 못할 때 영수증의 계정과 실제 청구 회사를 확인하도록 안내한다. 이 원칙을 ‘잘 모르겠어요’ 분기에 적용한다. [Apple 구독 취소 안내](https://support.apple.com/ko-kr/118428).

| 단계 | 고객이 받는 도움 | 확인할 정보 |
|---|---|---|
| 결제 경로 확인 | 저장한 경로 사용 또는 짧은 선택, 모르면 영수증·청구처 확인법 | 실제 청구처, 결제 계정, 필요한 관리 권한 |
| 해당 경로 열기 | 검증한 공식 관리 링크와 로그인 후 메뉴 순서 | 서비스·판매처, 기기·지역·언어 적용 범위 |
| 해지 진행 | 실제 메뉴 이름, 확인 화면과 다음 행동, 어디서 막혔는지 선택 | 갱신 중단인지 즉시 종료인지, 확인된 조건 |
| 완료 확인 | 공식 화면·확인 메일에서 무엇을 확인할지 안내 | 갱신 상태, 이용 종료일, 남은 청구 |
| 기록 갱신 | 완료/신청 대기/미완료를 고객이 기록 | 고객 확인 시점·출처, 다음 확인 행동 |

경로 예시로 Apple에서 결제한 iPhone 구독은 설정의 계정 화면에서 구독 목록과 해당 항목을 찾아 취소하는 흐름이다. 이는 2026-09-11에 확인한 공식 안내의 요약이며 모든 결제 경로에 적용하는 공통 순서가 아니다. [Apple 공식 단계](https://support.apple.com/ko-kr/118428).

Google Play는 결제 계정의 정기 결제 항목에서 취소하는 방법을 안내하며, 앱을 지우는 행동과 구독 취소를 구별한다. 가이드에도 이 구분을 반영한다. [Google Play 정기 결제 관리](https://support.google.com/googleplay/answer/7018481?hl=ko).

**안내 카드 — 공식 링크와 실제 순서, 막혔을 때의 도움을 함께 제공한다.**

가이드에는 대상 결제 경로, 사용할 기기/웹, 계정·권한 조건, 단계별 메뉴 이름, 공식 도움말·관리 링크, 완료 확인 위치, 확인일을 넣는다. 직접 관리 화면을 연결할 수 없으면 공식 도움말과 로그인 후 경로를 제공한다. 확인하지 않은 주소나 개인 세션 링크를 만들어 제공하지 않는다.

단계는 실제 흐름에 맞게 짧게 나누고 현재 단계와 앞뒤 이동을 제공한다. 스크린샷을 사용할 때는 대상 화면의 확인 시점을 표시하고 텍스트로도 따라갈 수 있게 한다. 로그인이나 실제 해지 버튼 실행은 고객이 공식 서비스에서 진행한다.

| 막힌 상황 | 안내와 복구 |
|---|---|
| 결제한 곳을 모름 | 고객이 영수증의 발신처·청구명과 결제 계정을 직접 확인하도록 설명; 민감한 영수증 업로드를 필수로 요구하지 않음 |
| 구독 목록에 서비스가 없음 | 다른 결제 계정·청구처·팀 계약 여부를 확인하고 해당 경로로 이동 |
| 취소 버튼이 없음 | 이미 갱신 중단인지, 권한이나 계약 방식이 다른지 확인; 버튼 부재만으로 완료 판정 금지 |
| 안내와 화면이 다름 | ‘화면이 달라요’ 제보, 공식 최신 도움말·고객지원 대안, 기존 진행 위치 보존 |
| 관리자만 변경 가능 | 필요한 권한과 공식 담당 경로 안내; 고객이 사용할 문의 문구 복사 제공 |
| 상담 신청이 필요함 | 공식 상담 접수 경로·확인된 처리 조건·접수 후 상태 확인법 안내 |
| 완료했는지 모름 | 공식 계정 상태·확인 메일·이용 종료일의 확인 위치 안내, 미확인으로 보존 |

환불·위약금·자료 접근·보관 기간·즉시 종료 여부는 해당 계약에 맞는 근거가 있을 때 표시한다. 모르면 ‘확인 필요’와 공식 확인 방법을 제공한다. 모든 서비스가 같은 시점에 종료되거나 환불된다고 설명하지 않는다. 전체 안내를 막는 체크리스트 대신 선택에 영향을 주는 조건을 해당 단계에 배치한다.

**완료 상태 — 가이드를 읽었다는 사실과 실제 구독 상태를 구분한다.**

진행 상태는 안내 전 → 안내 중 → 신청 후 확인 대기 또는 완료를 확인했다고 기록으로 관리한다. 외부 이동만으로 상태를 완료 처리하지 않는다. 고객의 확인은 ‘고객이 확인한 기록’으로 표시하고 서비스 연동 검증처럼 표현하지 않는다. 나중에 수정할 수 있게 한다.

갱신 중단, 이용 종료, 환불 처리는 독립된 값이다. 완료를 기록할 때 확인 가능한 종료일과 남은 결제를 함께 검토한다. 다음 갱신분은 확인된 상태에 따라 예정에서 제외하되 이미 약정한 청구는 유지한다. Google Play도 특정 결제 약정에서 갱신 중단 후 남은 납부가 존재할 수 있음을 설명한다. [Google Play 요금제 갱신 중지](https://support.google.com/googleplay/answer/7018481?hl=ko).

‘해지 완료’ 뒤 추천을 받으려면 고객이 별도로 선택한다. 기본 해지 길잡이는 무료 핵심 기능으로 두고 제휴 제안·구매를 완료 조건으로 삼지 않는다.

**관심 알림 — 보고 싶은 대상과 받아볼 이유를 고객이 선택한다.**

도구 상세의 ‘프로모션 알림 받기’, 비교 화면의 ‘이 후보들 행사 알림’, 내 도구함의 관심 알림 설정에서 시작한다. 특정 도구를 고르는 것만으로 모든 경쟁사 알림을 켜지 않는다.

| 관심 범위 | 연결 기준 | 예시 |
|---|---|---|
| 특정 서비스 | 고객이 직접 선택한 서비스의 공식 행사 | ‘관심 도구 A의 할인·무료 체험’ |
| 선택한 경쟁사 | 고객이 비교 후보로 고른 서비스 | ‘A와 비교 중인 B·C의 행사’ |
| 같은 업무의 대체재 | 고객이 대체재 포함을 선택한 작업·필수 기능 | ‘한국어 보고서 작업에 맞는 다른 도구’ |
| 학습 행사 | 고객이 별도 선택한 주제·유형 | 웨비나·워크숍·체험 행사; 가격 할인과 다른 유형 |

대체재는 같은 회사 분야라는 이유만으로 연결하지 않고 어떤 작업과 기능이 겹치는지 설명한다. 가격만 싸고 필수 기능이 없는 도구는 조건에 맞는 대체재 행사로 보내지 않는다. 신규 고객·교육 자격·지역·결제 경로 등이 맞지 않으면 맞춤 대상에서 제외한다.

처음에는 대상과 채널만 선택할 수 있게 하고, ‘월 환산 예산 이하’, ‘연간 선결제 제외’, ‘필요 기능’, ‘같은 기간 예상 절감액 이상’ 등 상세 조건은 선택 입력으로 둔다. 가격 비교에 필요한 요금제·기간·세금이 없으면 일반 행사 소식과 개인 절약 제안을 구분한다. 특정 자격 미확인 행사는 앱에서 조건을 표시할 수 있지만 적용 가능한 맞춤 이메일로 보내지 않는다.

**알림 내용 — 왜 나에게 왔는지와 실제 적용 조건을 먼저 보여준다.**

알림 카드에는 행사 대상·유형, 연결 이유, 공식 행사 가격·결제 주기·적용 기간·정상 갱신가, 신규/기존 고객 등 적용 조건, 마감 시각·시간대·출처·확인일을 넣는다. 절감액을 표시한다면 비교한 현재 플랜·기간·전환 비용·포기하는 기능도 함께 확인할 수 있게 한다.

다음은 문구 예시이며 실제 행사가 아니다.

> 보고서 작업으로 관심 등록한 A의 대안 B에 프로모션이 등록됐어요.
>
> 연간 선결제·신규 고객 대상이에요. 현재 플랜과 같은 기간의 비용과 필요한 기능을 비교해보세요.

대표 행동은 ‘조건·비용 비교’ 또는 ‘공식 행사 보기’다. ‘관심 없음’, 해당 서비스 숨기기, 조건 수정, 알림 끄기를 쉽게 제공한다. 기한이 확인되지 않았으면 임박 표시와 카운트다운을 만들지 않는다. 정가 대비 할인율을 고객의 실제 구독 대비 절감률로 바꾸지 않는다.

**알림 운영 — 수동 검수한 행사도 고객별로 연결하고 전달할 수 있게 한다.**

공식 출처에서 수집 → 운영 검수 → 대상·기간·자격 확정 → 관심 조건 연결 → 발송 직전 재확인 → 앱 알림함·이메일 전달 → 종료/수정 반영의 흐름이다. 첫 버전은 행사 등록·검수를 수동으로 시작하고 관심 매칭과 발송 이력 관리는 기능으로 제공한다. 전 시장 자동 수집이나 실시간 탐지를 약속하지 않는다.

이메일은 기본 비활성이다. 켤 때 하루 한 번 모아보기 또는 조건 충족 시 알림을 선택하며 시간대와 수신 시간을 확인한다. ‘조건 충족 시’는 확인된 행사를 처리하는 시점 기준이며 행사 발표 즉시 탐지한다는 의미가 아니다. 첫 출시의 외부 채널은 이메일 하나로 제한하고 앱 알림함에서 같은 항목을 이어 보게 한다.

운영 기본안은 일반 행사 이메일 하루 1회 묶음, 조건 충족 알림은 하루 최대 3회다. 한도를 넘는 행사는 앱에 모으고 다음 요약 전에 유효성을 재확인한다. 이 수치는 사용자 피드백으로 조정할 제안이며 서비스 보장이 아니다. 조건 충족 알림을 보낸 같은 행사는 다음 요약에서 다시 새 소식처럼 보내지 않는다. 해당 기간에 새로 맞는 행사가 없으면 발송하지 않는다.

같은 행사·고객·중요 변경 버전은 한 번 전달하도록 기록한다. 가격·자격·종료 조건이 의미 있게 바뀌면 기존 카드를 갱신하고, 고객 조건에 영향을 주는 수정만 재알림 후보로 둔다. 여러 서비스나 대체 관계로 같은 행사가 잡혀도 카드와 이메일을 반복 만들지 않는다. 마감 재알림은 고객이 선택한 행사에만 한 번 제공하는 후속 기능으로 둔다.

발송 직전에는 행사 유효성, 자격과 필요한 기능, 관심 설정, 채널 수신 동의를 다시 확인한다. 수신 해제 시 대기 중인 해당 채널 발송도 취소한다. 발송 실패 재시도는 같은 전달 건으로 처리하며 만료·해제 후에는 재시도하지 않는다. 전달 여부가 불확실하면 발송 기록을 먼저 확인해 중복을 줄인다. 발송 채널 오류가 앱 알림함의 기록을 지우지 않게 한다.

잘못된 가격·자격으로 이미 보낸 경우 원 카드에 수정 상태를 표시하고, 고객 판단에 영향을 주는 내용은 현재 수신 설정이 허용하는 채널로 정정한다. 설정상 발송할 수 없으면 앱에서 수정 내용을 확인할 수 있게 한다. 제휴비는 매칭·발송 우선순위에 영향을 주지 않으며 제휴 관계는 표시한다.

**데이터·운영과 검증 — 경로 정확성과 알림 관련성을 관리한다.**

| 관리 대상 | 필요한 정보·행동 |
|---|---|
| 해지 가이드 | 서비스·청구처·기기/지역·권한·공식 URL·단계·정책·확인일·버전·제보 상태 |
| 개인 해지 기록 | 계약·진행 위치·고객 확인 상태·확인 시점·이용 종료일·잔여 청구; 기본 비공개 |
| 행사 정보 | 서비스·유형·가격·적용 기간·마감 시간대·대상 자격·공식 출처·검수·종료/수정 상태 |
| 관심 규칙 | 고객·대상·대체재 포함 여부·업무/기능·가격/기간 조건·채널·시간·동의 상태 |
| 전달 기록 | 행사·고객·버전·채널·대기/발송/실패 상태·중복 방지 기준·재시도 |

가이드 확인은 공식 문서 확인과 실제 화면 확인을 구별한다. 실제 화면을 보지 않았으면 ‘공식 문서 기준’으로 표시한다. 단순 링크 정상 여부로 해지 절차 전체가 최신이라고 판단하지 않는다. 고객의 구독을 임의로 해지해 검증하지 않는다. 경로 변경 제보를 받으면 해당 부분을 재확인 중으로 표시하고 공식 지원 경로를 제공한다.

첫 출시에는 운영 가능한 핵심 도구·결제 경로의 안내, 진행·완료 기록, 검수한 행사, 관심 매칭, 앱 알림함·동의한 이메일을 포함한다. 이후 가이드 지원 범위, 자동 수집, 추가 채널, 결제 기한·마감 재알림을 확장한다. 기본 정보가 부족한 서비스에는 임의 안내를 채우지 않고 확인 가능한 범위를 밝힌다.

| 검증 사례 | 기대하는 결과 |
|---|---|
| iPhone 이용자이지만 웹에서 결제 | 저장/확인한 웹 청구 경로로 안내 |
| 결제 경로·계정 미상 | 영수증·청구처 확인을 도와 올바른 경로로 이동 |
| 메뉴 변경·권한 부족 | 다른 공식 경로와 지원을 제공하고 제보/진행 상태 보존 |
| 해지 안내 열람 또는 상담 접수만 수행 | 완료로 바꾸거나 예정 청구를 삭제하지 않음 |
| 갱신 중단 뒤 남은 약정 청구 | 다음 갱신과 잔여 약정을 구분해 비용에 반영 |
| 같은 행사를 여러 관심 관계에서 탐지 | 한 카드·한 전달 건으로 통합 |
| 신규 고객 전용인데 기존 고객으로 확인 | 적용 가능한 맞춤 행사 알림에서 제외 |
| 필수 기능·가격 조건 미확인 | 절약 확정이나 조건 충족 알림을 하지 않음 |
| 대기 중 행사 만료·수신 해제 | 발송과 재시도를 취소 |
| 조건 충족 알림 뒤 다음 날 요약 | 같은 행사를 새 행사로 중복 발송하지 않음 |

해지 기능은 고객이 올바른 메뉴를 찾고 완료/대기 상태를 설명할 수 있는지, 막힌 위치·경로 오류가 줄어드는지 검증한다. 프로모션은 열람률만 보지 않고 조건 일치, 실제 도움이 된 이유, 중복·불필요 알림과 해제 이유를 함께 본다. 실제 해지나 구매를 요구하지 않는 예시 과제로 먼저 사용성을 확인한다.
