# V16 커뮤니티 초안 복귀 및 화면 검증

이전 V15 차수는 실제 소스·비공개 배포가 바뀐 progress다. 현재 소스 b8d35c036f0541446fafa746652406a81b19f0a6, Site clean을 재확인했다. 기존 전체 구현·수정·검증·비공개 배포 승인이 적용된다.

원래 게이트4.3.3의 guest draft→authentication→restore와 실제 연결 중단을 UI에서 관찰한다. 일반 /community에서 도구 Claude 선택→글 작성→질문 초안→로그인 후 게시 경로를 로컬에서 재현했다. 로그인은 돌아왔지만 /community의 작성창0개·도구필터빈값으로 복귀하여 맥락이 사라졌다. URL에 write가 들어간 미리 구성한 양성 경로만으로는 이 문제를 발견할 수 없다.

변경은 원래 초안 저장 맥락(도구/답글 부모)을 유지한 안전한 내부 복귀 URL, 상세 답글의 write 처리, 열린 폼에서 맥락 전환 시 올바른 별도 폼 상태로 재생성에 한정한다. 로그인 전에 최신 폼 값을 동기 저장하고, 저장할 수 없을 때는 초안을 잃는 이동 대신 명시 오류를 보여준다. 로그인 복귀는 자동 게시하지 않으며 공개 동의는 새로 확인한다. 내용·닉네임은 URL에 넣지 않는다. 일반 작성/도구 필터/기존 직접 작성 링크/답글을 별도 확인한다.

실제 연결 중단은 확인된 로컬 dev process를 통제해 중단·회복시키는 방식으로 관찰한다. 새로운 임의 endpoint나 운영 장애를 만들지 않는다. 실사용 후기는 만들지 않고 통제된 로컬 초안/fixture와 실제 사용자/운영 데이터를 구분한다. 서버 수락 후 응답 유실과 신규 제출 중복 가능성은 단순 연결 중단 관찰만으로 해결했다고 주장하지 않는다.

병행 검증: 기존 V10 S01–S12 확장 인벤토리와3.4.4/7.2.4 기준을 보존한다. 실제 Mac 확대·VoiceOver는 컴퓨터 도구가 잠금 오류를 반환했고 super+plus는 브라우저 scale/폭을 바꾸지 않았다. 사용자에게 직접 잠금 해제를 요청했으며 답변 전 수행한 것으로 간주하지 않는다. Sites 실제 cron 등록/조회 계약은 독립 조사에서 확인되지 않았으므로 구현물만으로 무인운영을 PASS하지 않는다.
