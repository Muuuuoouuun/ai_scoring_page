# AIs 제작 요구사항과 검증 기준

## 우선순위

2026-09-12 최신 사용자 목표와 정정 사항 > 통합 기획 v0.6 > 페이지 구조 명세 > 구독·해지·알림 상세 명세 > 과거 기획과 이미지. 이미지는 참고이며 복제 대상이 아니다. 기본 홈은 AI·SaaS 정보 발견이고, 개인 관리는 별도 마이페이지다.

## 요구사항

1. 한국어 정보 중심 홈, 다섯 상위 메뉴(발견, 도구 탐색, 소식·행사, 커뮤니티, 마이페이지), 반응형 탐색.
2. 실제 AI·SaaS·앱·AI 모델 카탈로그. 공식 출처 기반 기능, 로고, 업데이트, 확인일 및 미확인 상태. 모델과 앱을 구별한다.
3. 이름·기능·목적 검색, 카테고리·필수 조건 필터, 이유 있는 추천, 최대 세 도구 비교. 미확인을 조건 충족으로 간주하지 않는다.
4. 도구 상세: 개요, 항목별 점수와 근거, 주요 기능과 조건, 유사 앱, 활용법, 업데이트, 후기. 직접 평가하지 않은 항목은 미평가이며 점수를 만들지 않는다.
5. 공개 활용법·소식·행사와 원문 출처. 과거 행사는 종료 상태. 가입 없이 정보 열람과 비교가 가능해야 한다.
6. ChatGPT 로그인, 서버에서 식별한 계정별 영속 저장. 데이터는 D1을 사용하고 계정 간 격리를 검증한다.
7. 사용자 평가(사용 업무·플랜·일자 포함), 기능 제안, 후기·질문·댓글·신고와 자기 글 관리. 사용자 경험과 검수된 공식 사실을 분리한다.
8. 내 도구함 상태·목적·메모, 직접 서비스 추가, 업무별 모음, 콘텐츠 저장·기록. 로그인 전 초안은 보존하며 실패를 성공으로 표시하지 않는다.
9. 복수 계약의 구독 금액·통화·주기·다음 결제·상태, 월 환산/실제 결제/예상 결제 구분, 미입력 금액 별도 표시. 번들 중복 방지.
10. 동일 기간·필수 기능·선결제 조건의 절약 비교. 결제 경로별 해지 안내와 신청/확인/종료/잔여 청구 기록.
11. 관심 서비스·대안 프로모션 조건, 만료·자격·중복 처리, 앱 알림과 동의한 이메일 수신·해제. 최신 업데이트 동기화의 실제 동작과 확인 시각을 드러낸다.
12. 데이터 내보내기·삭제, 접근성, 입력 검증·오류 복구, 운영 검수, 개인정보 안내.
13. Sites 실배포 URL, 주요 화면/로그인/저장/커뮤니티/조회 흐름을 로컬과 배포 환경에서 검증.

## 엄격한 평가

각 영역을 100점 만점으로 따로 평가하고 모두 88점 이상이어야 완료한다. 점수는 검증한 기준의 획득점 합계이며 목표에 맞춰 역산하지 않는다. 미검증은 미획득, 실제 기능이 없는 목업·로컬 전용 저장·허위 최신 정보는 구현으로 인정하지 않는다. 보안·개인정보 중대 결함, 깨진 핵심 흐름, 배포 실패가 있으면 해당 영역은 최대 60점이다.

## 구현 위치와 작업 순서

현재 루트의 Next.js 14 초기 구현은 보존하고, Sites 호환 앱을 `site/`에서 제작한다. 이 디렉터리가 배포 소스 루트다. 기존 자료를 검토·이식하되 고정 관리자 ID와 근거 없는 점수는 사용하지 않는다.

- [x] 공식 카탈로그·로고·업데이트와 콘텐츠 조사

각 단계는 완료 근거를 얻은 뒤 체크한다. 88점 미달 또는 명시 요구사항 미구현이 남으면 목표를 완료로 표시하지 않는다.

현재 소유자 전용 배포. 최신 배포 성공 응답을 확인했다. 일반 사이트 이용자에게 보이는 인증과 별개로 Sites 접근 범위가 적용된다. 원본 참고 이미지를 복제하지 않고 성숙한 아이보리·노랑·파랑 테마와 별도 화면 구성을 사용했다.
