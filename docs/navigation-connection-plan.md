# Navigation Connection Plan

## 역할 분리

- GNB: 전역 목적지. `탐색`, `신호`, `방법론`으로 정리하고, 도구 상세 페이지는 `탐색` 흐름에 포함한다.
- JournalRail: 데스크 목차. `저널 데스크`, `문제 탐색`, `커뮤니티 신호`, `방법론`으로 작업 흐름을 보여준다.
- Tool tabs: 상세 페이지 안의 판단 모드. `판단 리뷰`, `도입 토론`, `현장 신호`로 나누고 `?view=` 쿼리로 공유 가능하게 유지한다.

## 연결 규칙

- `/`는 브랜드와 대표 리뷰 진입점이다.
- `/search`와 `/tools/[id]`는 같은 탐색 흐름으로 active 처리한다.
- `/community`는 전체 커뮤니티 신호 페이지와 상세 페이지의 현장 신호 탭을 연결하는 축이다.
- `/about`은 큐레이션 기준과 커뮤니티 운영 방식을 설명하는 방법론 페이지다.

## 다음 보강 후보

- JournalRail을 페이지별 섹션 앵커로 확장한다.
- Search 페이지에 `문제`, `배지`, `결과`의 내부 탭/앵커를 추가한다.
- About과 Community의 오래된 glass 카드 스타일을 Journal 패널 토큰으로 더 정리한다.
