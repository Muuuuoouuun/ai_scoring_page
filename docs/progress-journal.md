## 2026-09-15 업데이트: 평가 콘텐츠 조사 채움 + 점수·별점·비교·추천 시스템

### 1) 평가 콘텐츠를 외부 조사로 채움
- 기존 10개 SaaS(Notion, Figma, Slack, Linear, Airtable, Miro, Zapier, Jasper, Gong, Replit)에 더해 AI 서비스 15개를 추가해 총 25개 도구를 다룹니다.
  - AI 어시스턴트: ChatGPT, Claude, Gemini, Perplexity, Microsoft 365 Copilot
  - AI 빌더/크리에이티브: GitHub Copilot, Cursor, Lovable, Midjourney, Canva
  - AI 리서치/브라우저/에이전트: NotebookLM, Perplexity Comet, ChatGPT Atlas(2026-08 서비스 종료, 종료 표시), Dia, Manus
- 도구마다 `data/evaluations.ts`에 조사 기반 평가를 채웠습니다: 한줄 총평, 5축 점수, 핵심 기능/AI 기능, 가격 요약, 한국 팀 사용 메모, 경쟁 도구 3종 비교(되는 것/안 되는 것), 2025~2026 패치·장애·정책 변경 이력(영향도 포함), 실무 플레이북 3종, G2·Capterra·Product Hunt·앱스토어 등 외부 사이트 평점, 참고 출처 링크.
- 조사는 하위 모델 서브에이전트 5개(도구 5개씩)와 기능 매트릭스 전담 1개가 웹 검색으로 수행했고, 놀라운 발견(Atlas 종료, Meta의 Manus 인수 불허, Airtable 인수, Claude Fable 5.1 출시, Midjourney/Canva 2026 업데이트)은 메인 세션에서 재검색으로 교차 확인했습니다. 확인하지 못한 세부 수치는 본문에 "(확인 필요)"로 남겼습니다.
- 환경 제약: 페이지 직접 fetch는 프록시에서 차단돼 검색 결과 요약 기반으로 조사했습니다. 출처 URL은 각 도구의 참고 자료에 남겨 재검증할 수 있게 했습니다.
- 생성 파이프라인: 연구 JSON → `scripts/merge-research.js` → `data/tools.ts`, `data/evaluations.ts`, `data/capabilities.ts`. 스크립트가 날짜 형식, 점수 범위, 항목 개수, URL 형태를 검증하고 경고를 출력합니다.

### 2) 점수 시스템 (`lib/scoring.ts`)
- 편집 점수 = 5축 가중 평균 (기능 완성도 25%, UI/UX 15%, 에러/안정성 25%, 쾌적도 15%, 가격 합리성 20%).
- 외부 평가 점수 = 외부 리뷰 사이트 평점을 100점으로 정규화한 뒤 사이트별 신뢰 가중치(G2·Capterra·TrustRadius 1.0, Product Hunt·앱스토어 0.8, Trustpilot 0.5)로 가중 평균. 설문 재인용·리뷰 건수처럼 점수가 아닌 항목은 자동 제외.
- 종합 점수 = 편집 70% + 외부 30% (외부 평가가 없으면 편집 100%). 등급: 85+ 강력 추천, 75+ 추천, 65+ 조건부 추천, 그 외 신중 검토. 전체/카테고리 순위를 함께 표시.

### 3) 별점 시스템
- 편집팀 별점(종합 점수/20)과 커뮤니티 별점(사용자 리뷰 평균, 1~5점 분포 히스토그램), 외부 사이트 별점을 리뷰 페이지 "별점 요약" 카드에 표시.
- 리뷰 저장을 `lib/reviews.ts`로 분리하고 커스텀 이벤트로 동기화해, 리뷰를 등록하면 별점 요약이 즉시 갱신됩니다(현재는 브라우저 로컬 저장).
- 검색/홈/추천 카드에 별점·등급·종합 점수를 노출.

### 4) 비교 시스템
- `/compare` 페이지: 최대 3개 도구를 종합 점수·5축·임팩트 4축·판단 배지·기능 지원 매트릭스(지원/부분 지원/미지원 10개 항목)·가격·핵심 기능·외부 평가·최선/최악 시나리오로 나란히 비교. 축별 선두를 강조하고 "차이 요약"을 자동 생성.
- 모든 카드와 리뷰 헤더에 "비교함 담기" 버튼, 하단 고정 비교함 트레이 추가.

### 5) 추천 시스템 (`lib/recommend.ts`)
- `/recommend` 페이지: 직군(7종), 팀 규모(4종), 우선순위(최대 2개), 제약 조건(락인 회피·한국어 필수·무료 플랜 필수)을 고르면 적합도(0~100)를 계산하고 추천 이유와 주의할 점을 함께 보여줍니다.
- 적합도 = 종합 점수(최대 35) + 우선순위 지표(최대 35) + 직군 적합(최대 15) + 팀 규모 적합(최대 10) ± 제약 조건 가점/감점. 서비스 종료 도구는 제외.
- 리뷰 페이지의 "함께 비교할 도구"를 유사도(공유 문제 상황, 카테고리, 대안 관계, 임팩트 코사인 유사도, 직군 겹침) 기반으로 교체.
