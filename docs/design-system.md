# g2 디자인 시스템

`app/globals.css` 상단의 파운데이션 블록이 이 문서의 원본입니다. 값을 바꿀 때는
컴포넌트 규칙이 아니라 토큰을 먼저 수정하세요.

## 1. 색상 채널

테마 전환이 가능한 원시 채널입니다. `rgb(var(--c-x) / <alpha>)` 형태로만 씁니다.

| 채널 | 용도 | Light | Dark |
| --- | --- | --- | --- |
| `--c-paper` | 떠 있는 표면(카드/패널) | `255 255 255` | `38 35 31` |
| `--c-ink` | 호버/헤어라인/미세 틴트 | `43 45 51` | `240 236 228` |
| `--c-signal` | 브랜드 골드 | `176 138 82` | `211 168 105` |
| `--c-shadow` | 그림자 | `69 60 52` | `0 0 0` |
| `--c-warm` | 따뜻한 보더 | `208 196 188` | `122 110 96` |
| `--c-white` | 항상 흰색(다크 패널 내부 전용) | `255 255 255` | 동일 |

`--c-ink`는 라이트에서 어둡고 다크에서 밝습니다. 따라서 호버 틴트는 두 테마에서
자동으로 올바른 방향(라이트=어둡게, 다크=밝게)으로 동작합니다. 그림자는 항상
`--c-shadow`를 써야 다크에서 빛나 보이지 않습니다.

## 2. 시맨틱 토큰

- **텍스트**: `--ink-strong`(제목) · `--ink`(본문) · `--muted-strong`(보조 본문) · `--muted`(캡션)
- **표면**: `--surface-card` / `--surface-card-hover` / `--surface-sunken`(입력·홈 배경 틴트)
- **반전 패널**: `--surface-inverse` 위에서는 `--on-inverse`, `--on-inverse-muted`,
  `--on-inverse-accent`만 사용합니다. 일반 텍스트 토큰을 쓰면 다크에서 대비가 무너집니다.
- **강조**: `--accent`(텍스트로 쓸 수 있는 대비 확보 골드) vs `--accent-decor`(막대·괘선 등 장식 전용)
- **판단 배지 역할**: `--positive*`(시간 절약) · `--caution*`(신중한 사용) · `--risk*`(락인 위험).
  각 역할은 `-ink`/`-bg`/`-border` 3종 세트로 제공합니다.

## 3. 타이포그래피

- 서체: 제목 `Epilogue`, 본문 `Noto Sans KR`, 숫자·라벨 `IBM Plex Mono`
  (`next/font`로 셀프 호스팅 — 외부 CDN 의존성 없음)
- 스케일은 `--fs-xs` ~ `--fs-4xl`이며 `--fs-xl` 이상은 `clamp()` 유동 스케일입니다.
  화면 크기별로 폰트 크기를 직접 지정하지 말고 스케일을 쓰세요.
- 한국어는 `word-break: keep-all`이 전역 적용되어 단어 중간에서 줄이 끊기지 않습니다.
  URL·영문 장문 대비로 `overflow-wrap: anywhere`를 함께 둡니다.

## 4. 간격 · 형태 · 모션

- 간격: `--sp-1`(0.25rem) ~ `--sp-16`(4rem), 섹션 사이는 `--section-gap`,
  좌우 여백은 `--gutter`
- 라운드: `--r-sm` 8px → `--r-2xl` 28px, 알약형은 `--r-full`
- 그림자: `--e-1`(카드 기본) / `--e-2`(호버·패널) / `--e-3`(히어로), 유리 하이라이트는 `--inset-hi`
- 모션: `--dur`(220ms) + `--ease`. `prefers-reduced-motion`에서 전역 비활성화됩니다.

## 5. 레이아웃

- 컨테이너 `--container`(1180px), 사이드 레일 `--rail-w`(236px), GNB 높이 `--nav-h`(68px)
- 1180px 이상에서 `body`에 레일 폭만큼 좌측 패딩이 생기고 레일은 `position: fixed`로
  붙습니다. GNB만 음수 마진으로 전체 폭을 유지합니다.
- 1180px 미만에서는 레일이 사라지고 본문이 전체 폭을 씁니다.

## 6. 테마

- 기본은 시스템 설정(`prefers-color-scheme`)을 따릅니다.
- GNB의 토글이 `<html data-theme="light|dark">`를 설정하고 `localStorage`에 저장합니다.
- `app/layout.tsx`의 인라인 부트스트랩 스크립트가 첫 페인트 전에 값을 적용해
  깜빡임을 막습니다.

## 7. 작업 규칙

1. 새 색상이 필요하면 하드코딩하지 말고 시맨틱 토큰을 추가합니다.
   두 테마 블록(미디어쿼리 + `[data-theme="dark"]`)에 모두 정의해야 합니다.
2. 대비는 자동으로 검증합니다. 텍스트는 4.5:1, 큰 텍스트는 3:1 이상을 유지하세요.
3. 상태 표시(성공/주의/위험)는 색만으로 구분하지 않습니다. 배지에는 점 마커,
   비교표에는 열 제목을 함께 둡니다.
4. 인라인 `style` 대신 클래스를 씁니다. 인라인 값은 테마를 따라가지 못합니다.
