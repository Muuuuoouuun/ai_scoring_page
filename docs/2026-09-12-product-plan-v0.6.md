**AI Score / AIs — AI·SaaS 정보 탐색과 개인 활용을 함께 다루는 기획서 v0.6**

작성일: 2026-09-12. 서비스명은 가칭이다. 최초의 AI·SaaS 정보·평가·추천·뉴스·행사·커뮤니티 기획과 이후의 개인 서비스·구독 관리 논의를 통합한다. 이번 사용자 지시에 따라 **정보를 얻는 경험은 개인 관리와 최소 동등한 비중을 갖고, 서비스의 대표 정체성과 기본 홈에서는 정보 탐색을 먼저 드러낸다.** 이전 버전의 개인 페이지 중심 설명과 충돌하면 이 문서를 우선한다. 구현 완료나 조사 결과를 의미하지 않는다.

**정체성 — AI·SaaS의 기능·평가·활용법·소식을 쉽게 이해하고, 발견·비교·경험 공유와 개인 관리까지 이어갈 수 있는 정보·추천 커뮤니티.**

고객은 새로운 서비스를 발견하고, 기능과 차이를 이해하고, 업데이트·뉴스·행사를 확인하며 다른 사람의 경험에서 배운다. 필요한 경우 자신의 서비스와 구독을 개인 페이지에 정리하고 활용·비용·해지를 관리한다.

**‘새로운 정보를 얻고 이해했다’는 것만으로도 완결된 고객 가치다.** 도구 선택·실행·가입·저장·구독 관리로 이어지지 않은 방문도 유익할 수 있다. 이 서비스에 등록한 도구가 없어도 주요 기능을 이용할 수 있어야 한다.

정보와 개인 관리의 비중은 화면을 정확히 반으로 나누거나 방문 시간을 50:50으로 강제하는 의미가 아니다. 기획 우선순위·기본 홈·탐색 경로·개발과 콘텐츠 운영 계획·성과 검토에서 정보 경험이 계속 밀리지 않게 하는 기준이다. 정보와 개인 관리가 연결되는 검색·추천·공통 데이터는 양쪽에 필요한 기반으로 관리한다.

**고객 경험의 두 축은 각각 혼자서도 유익해야 한다.**

| 축 | 고객이 찾아오는 이유 | 완결되는 경험 |
|---|---|---|
| AI·SaaS 정보·발견·커뮤니티 | 무엇이 있는지, 무엇이 다른지, 어떻게 쓰는지, 무엇이 바뀌었는지 알고 싶음 | 필요한 정보를 찾고 이해하거나, 비교·활용법·사람들의 경험에서 도움을 얻음 |
| 개인 활용·관리 | 내 도구·관심·사용 기록·구독을 정리하고 관리하고 싶음 | 기록을 다시 찾고, 비용·유지·전환·해지·관심 알림을 자신의 조건에 맞게 관리 |

개인 기록이 추천을 돕고 공개 정보가 개인 관리에 활용될 수는 있지만, 모든 이용을 ‘도구 등록부터 시작하는 과정’으로 만들지 않는다. 커뮤니티도 개인 기록을 공개하는 방식 외에 질문·토론·직접 작성한 활용 경험으로 참여할 수 있게 한다.

**고객과 친절함 — 가벼운 정보 탐색부터 구체적인 관리까지 수용한다.**

초기 한국어 고객의 방문 목적을 다음과 같이 가정한다. 리서치·문서·콘텐츠 업무는 깊이 검증할 초기 과제 후보로 유지한다. 전체 서비스의 정보 범위를 그 세 업무로 한정한 것으로 해석하지 않는다.

| 방문 목적 | 고객의 말 | 첫 도움 |
|---|---|---|
| 정보·흐름 파악 | ‘최근 AI·SaaS에 뭐가 새로 나왔지?’ | 중요한 변화와 의미를 쉽게 이해 |
| 도구·기능 탐색 | ‘이런 기능이 있는 서비스가 있나?’ | 가능한 도구·방법과 차이를 발견 |
| 활용·경험 학습 | ‘다른 사람들은 어떻게 쓰고 있지?’ | 따라 할 수 있는 예시나 참고할 경험 확보 |
| 개인 정리·관리 | ‘내가 쓰는 것과 결제를 정리하고 싶어’ | 서비스·구독을 기록하고 필요한 행동 확인 |

기존의 내부 검토 기준인 사용 편의·친절함 40%, 실제 유익 30%, 재미·재방문 동기 20%, 확장성·운영 지속성 10%는 기능을 평가하는 제안치로 유지한다. **이 비중은 정보/개인 영역의 배분이나 도구 평가 점수가 아니다.** 출처 정확성·공개 범위·기본 접근성은 별도의 기본 조건이다.

**메뉴 구조 — 정보의 종류와 개인 공간을 쉽게 구분한다.**

| 메뉴 | 주요 내용 | 대표 행동 |

| 발견 | 새 도구, 편집자 추천, 활용 예시, 주제별 큐레이션 | 몰랐던 도구·기능·쓰임을 알아봄 |
| 도구 탐색 | 카테고리·기능/목적 검색, 상세 정보, 평가·비교, 대체재 | 필요한 기능과 도구의 차이를 이해 |
| 소식·행사 | AI·SaaS 뉴스, 제품 업데이트, 출시, 할인·체험, 웨비나·워크숍 | 변화·적용 조건·참여 기회를 확인 |
| 커뮤니티 | 사용 후기, 질문·토론, 활용법·조합, 제작자의 제품 소개 | 경험을 읽고 질문하거나 공유 |
| 마이페이지 | 내 도구함, 관심·사용 기록, 구독·비용·해지 관리, 알림 설정 | 자신의 정보를 정리하고 관리 |

앞선 ‘내 도구함’은 마이페이지 안의 서비스 정리 기능 이름으로 사용한다. 마이페이지의 내용은 기본 비공개다. 일반 정보·공개 경험 열람과 검색·비교는 로그인 없이 제공한다. 계정은 개인 기록 보관·개별 알림 설정·공개 작성처럼 필요한 시점에 연결한다.

뉴스·업데이트·행사는 전체 목록과 주제별 탐색 경로를 갖는다. 사용 중인 서비스와 관련된 항목만 보거나 프로모션만 모으는 것은 필터다. 모든 정보가 내 구독이나 구매 의도에 연결되어야 노출되는 구조로 만들지 않는다.

**기본 홈 — 로그인 여부와 관계없이 정보를 얻는 화면으로 연다.**

| 홈 영역의 우선 흐름 | 고객에게 보여줄 것 |
|---|---|
| 공통 검색·대표 설명 | 서비스명·기능·하고 싶은 일·알고 싶은 내용을 검색 |
| 오늘 알아볼 것 | 중요한 AI·SaaS 변화, 새 도구, 편집자가 고른 주요 내용 |
| 도구 발견·카테고리 | 어떤 일에 쓰는지와 기능·차이를 보여주는 카드 |
| 비교·활용 안내 | 근거 있는 비교, 결과 예시, 쉽게 시작하는 방법 |
| 소식·행사 | 최신 확인 소식·업데이트, 일정·마감과 참여 조건 |
| 사람들의 경험 | 참고할 사용 후기·질문·활용 조합 |

재방문자에게도 공개 정보를 얻는 기본 홈을 유지한다. 마이페이지 바로가기, 저장한 비교 이어보기, 관심 주제 강조는 함께 제공할 수 있지만 홈 전체를 개인 구독 현황으로 바꾸지 않는다. 고객이 직접 마이페이지로 이동하거나 브라우저에 해당 페이지를 저장해 이용하는 것은 가능하다.

정보 카드의 핵심은 도구명·긴 홍보문보다 ‘무엇인지’, ‘어디에 쓸 수 있는지’, ‘무엇이 달라졌는지’다. 무한한 정보량보다 이해 가능한 요약과 더 깊이 볼 수 있는 원문·상세 연결을 제공한다. 방문할 때마다 새 내용을 억지로 만들거나 근거 없는 인기 순위를 표시하지 않는다.

**정보 기능 1 — 도구 정보와 발견: 어떤 서비스인지 쉽게 이해한다.**

AI·SaaS별로 한 문장 소개, 주요 기능, 잘 맞는 업무, 대상 고객, 결과 예시, 시작 난이도, 비용·무료 범위, 한국어·입출력·플랫폼·연동·제약을 제공한다. 카테고리·업무·기능·조건으로 둘러보고 관련 도구·대체재·활용법으로 이어갈 수 있게 한다.

기본 정보의 폭과 직접 평가의 깊이를 구분한다. 카테고리 확장은 검수할 수 있는 범위에서 진행하고, 기본 정보를 제공하는 도구를 모두 직접 평가한 것처럼 표시하지 않는다. 신규·추천·편집자 선정에는 기준과 확인 시점을 표시한다.

**정보 기능 2 — 검색·추천: 이름을 몰라도 정보를 찾는다.**

서비스명, ‘PDF 요약’ 같은 기능, ‘자료를 출처와 함께 정리하고 싶어’ 같은 목적, 제품 변경이나 행사에 관한 질문을 받는다. 결과는 도구·비교·활용법·소식·업데이트·행사·공개 경험으로 구분한다. 사실을 찾는 질문에 무조건 구매 후보만 제시하지 않는다.

기본 검색 범위는 공개 정보 전체다. 검색 맥락에 따라 업무·가격·언어·기간·콘텐츠 유형 등의 필터를 제공하고 이해한 조건을 수정할 수 있게 한다. ‘내 도구 반영’은 선택 사항이며 이를 켜도 현재 질문의 조건을 우선한다. 내 도구함 내부 검색은 범위를 명확하게 표시한다.

추천은 업무·기능의 연관성, 확인한 근거, 비교할 차이를 설명한다. 유사 서비스·보완 조합·새 활용법·관심 주제를 구분한다. 개인화가 없어도 현재 보고 있는 콘텐츠와 검색 조건을 바탕으로 관련 정보를 연결한다. 새로운 도구와 분야를 살펴볼 수 있는 일반 탐색 경로도 계속 제공한다.

첫 버전의 방법은 이름·별칭·한국어 동의어·기능/업무 태그·구조화된 조건·검수한 관계를 이용한 탐색이다. 필요할 때 의미 검색을 비교 검증한다. 기능·요금제·연동 사실은 출처로 확인하고, 미확인을 충족으로 처리하거나 결과가 없을 때 필수 조건을 몰래 완화하지 않는다.

**정보 기능 3 — 스코어링·비교: 평가와 판단 근거를 공개한다.**

초기 논의의 스코어링은 핵심 정보 기능으로 유지한다. 점수만 보고 결론을 오해하지 않도록 평가 대상·업무·과제·요금제/버전·평가일·방법·결과·강점·한계를 함께 제공한다. 모델 벤치마크와 그 모델을 이용하는 앱의 실제 사용 평가는 구분한다.

| 평가·비교 정보 | 보여줄 것 |
|---|---|
| 기능·조건 | 가능·불가능·조건부·미확인, 적용 요금제·환경 |
| 실무 평가 | 동일 과제의 품질·효율·한국어·비용 대비 효용·작업 연결성, 결과 예시 |
| 사용자 경험 | 사용 시점·목적·플랜·잘된 점·한계, 자기보고 여부 |
| 근거 상태 | 공식 자료 확인·직접 테스트·재확인 필요, 표본·확인일 |
| 나란히 비교 | 같은 목적의 소수 후보에서 얻는 것과 포기하는 것 |

평가가 없으면 평가 대기로 표시하고 기본 정보는 제공한다. 미실시를 0점으로 표시하지 않는다. 초기에는 조건이 확인된 항목별 평가와 개별 경험을 제공하고, 표본·집계 기준이 마련되기 전 임의의 전체 순위나 개인 적합성 백분율은 만들지 않는다. 조회·저장·제휴 수익을 성능 점수에 섞지 않는다.

**정보 기능 4 — 활용법·학습: 어떻게 쓰는지 이해하고 필요한 만큼 시도한다.**

활용 예시에는 어떤 결과를 만들 수 있는지, 준비물·가능한 플랜·입력 예시·단계·결과 확인·막힘 해결을 제공한다. 한 도구의 사용법뿐 아니라 두 도구를 이어 쓰는 방식과 다른 접근의 차이도 설명한다. 자동 연동과 수동 복사·내보내기 조합은 구분한다.

고객이 읽고 작업 방법을 이해하는 것도 가치다. 직접 해보고 싶으면 예시 입력과 공식 도구 링크를 제공한다. 실행은 외부 도구에서 고객이 하며 클릭·복사를 실제 성공으로 집계하지 않는다. 안내 저장과 사용 결과 기록은 선택 사항이다.

**정보 기능 5 — 소식·업데이트·행사: 변화와 기회를 독립적으로 다룬다.**

| 콘텐츠 유형 | 고객이 얻어갈 정보 | 필수 구성 |
|---|---|---|
| AI·SaaS 뉴스·해설 | 무슨 일이 있었고 어떤 의미가 있는지 | 핵심 사실·배경·영향·출처·사건/작성 시점 |
| 제품 업데이트 | 어떤 기능·조건이 달라졌는지 | 변경 전후·적용 대상·제공 상태·확인일·테스트 여부 |
| 신규 서비스·기능 소개 | 어떤 일을 할 수 있고 무엇이 다른지 | 쓰임·결과 예시·시작 조건·제약 |
| 활용 큐레이션 | 특정 목적에 어떤 방법들이 있는지 | 선정 이유·공통 목적·차이·시도 방법 |
| 할인·체험 행사 | 누구에게 어떤 조건으로 유리한지 | 가격·대상 자격·기간·정상 갱신가·공식 링크 |
| 웨비나·워크숍·행사 | 무엇을 배우거나 참여할 수 있는지 | 주제·대상 수준·주최·일시/시간대·방식·비용·신청 마감 |

등록한 서비스와 무관하게 전체·주제별 최신 내용을 볼 수 있다. 관심 도구·업무 필터와 알림은 이를 개인에게 맞게 다시 보여주는 기능이다. AI·SaaS를 이해하는 데 도움이 되는 테크 배경 소식도 편집 범위에 포함할 수 있다.

뉴스와 행사를 ‘마이페이지로 돌아오게 하는 보조 콘텐츠’로만 취급하지 않는다. 콘텐츠 자체가 질문에 답하도록 충분한 맥락과 출처를 제공한다. 발표 상태와 직접 검증 여부를 나누고, 날짜가 지난 행사는 진행 중인 기회로 노출하지 않는다. 실제 시장의 모든 뉴스를 실시간으로 수집한다고 약속하지 않는다.

**정보 기능 6 — 커뮤니티: 사람들의 경험과 질문에서 배운다.**

도구·업무별 후기, 질문·답변, 활용 사례, 조합 비교, 제품 제작자의 소개·피드백을 다룬다. 개인 도구함 등록이나 구독 기록을 작성의 전제로 요구하지 않는다. 개인 기록에서 공개할 부분을 골라 공유하는 경로도 유지한다.

후기는 작업·플랜·사용 시점·결과를 알 수 있게 받고, 단순 반응과 실사용 평가는 구분한다. 제작자·업체 관계·제공받은 혜택을 표시한다. 원 작성자를 남기고 다른 사람의 경험을 원본과 연결한다. 질문 접수·답변 확인·오류 제보 경로를 제공한다.

첫 공개는 검수한 경험 열람·짧은 반응·질문 접수로 시작할 수 있다. 공개 작성·답변의 범위는 운영 여력에 맞춰 늘린다. 참여가 적을 때에는 공식 정보·평가·가이드를 제공하고 존재하지 않는 후기나 활동을 채우지 않는다.

**개인 페이지 — 각자의 정보를 관리하는 기능을 유지한다.**

| 마이페이지 안의 기능 | 유지하는 내용 |
|---|---|
| 내 도구함 | 사용 중·시험 중·관심·중단 상태, 목적, 업무별 모음, 메모 |
| 저장·활동 기록 | 도구·비교·활용법·소식·행사 저장, 선택 이유, 사용 결과 |
| 내 구독·비용 | 계약별 금액·통화·주기·다음 결제, 월 환산과 실제/예상 지출 구분 |
| 절약 비교 | 필수 기능·기간·선결제 조건을 고려한 요금제·할인·대안 비교 |
| 해지 관리 | 결제 경로별 안내, 진행 상태·완료 확인·이용 종료·잔여 청구 기록 |
| 관심 알림 | 관심 서비스·선택한 경쟁사·대체재의 프로모션, 조건·채널·수신 설정 |

개인 페이지는 계정에 기록을 보관하며 여러 기기에서 이어서 이용한다. 모르는 정보를 입력하도록 강요하지 않고 저장 실패 시 입력·재시도를 보존한다. 목록에 없는 서비스도 개인 항목으로 추가할 수 있지만 공개 카탈로그의 검증된 정보로 자동 취급하지 않는다. 서비스 하나의 복수 계약과 번들 비용의 중복 합산을 구분한다.

일반 해지 방법·공개 프로모션·도구의 공식 가격은 공개 정보로도 찾을 수 있다. 개인 페이지에는 고객의 계약에 맞는 계산·진행 상태·알림을 연결한다. 개인 비용·메모·계약은 기본 비공개이고 공개 경험과 분리한다. 기본 공개 정보에 접근하기 위해 개인 정보를 입력할 필요가 없어야 한다.

월 환산과 실제 결제의 차이, 미확인 금액, 환율·세금·할인 종료, 선결제·전환 비용·남은 약정의 처리 기준은 [구독 관리·비용 최적화 상세 기획](/Users/bigmac_moon/dev/ai_score/docs/superpowers/specs/2026-09-11-subscription-optimization-design.md)을 유지한다. 고객이 고른 기간과 필수 기능을 충족하는 범위에서 비교하고, 예상 절약을 확인된 성과로 표시하지 않는다.

결제 경로별 해지 안내와 관심 프로모션의 앱 알림함·수신 동의한 이메일은 [해지 길잡이·관심 알림 상세 기획](/Users/bigmac_moon/dev/ai_score/docs/superpowers/specs/2026-09-11-cancellation-promotion-alerts-design.md)을 유지한다. 해지 방법 앞에 구매 제안을 끼우지 않고, 행사 자격·만료·중복·수신 해제를 확인한다. 개인화 알림을 원하지 않는 고객도 공개 행사 목록을 탐색할 수 있다.

구독·해지·알림의 상세 문서는 해당 기능의 명세다. 그 문서의 분량이나 세부 수준이 전체 서비스의 우선순위를 뜻하지 않는다. 전체 구조·홈·출시·성과 기준은 이 통합 기획서를 따른다.

**사용·유익·재미 — 정보를 알아가는 즐거움도 중심에 둔다.**

| 고객 순간 | 유익 | 재미·감정의 가설 |
|---|---|---|
| 새 도구·기능을 이해함 | 가능한 일과 선택지를 넓힘 | ‘이런 것도 있네’라는 호기심과 발견 |
| 뉴스·업데이트를 읽음 | 변화의 의미와 영향을 파악 | 흐름을 이해하는 만족 |
| 평가·비교를 봄 | 차이와 판단 근거를 얻음 | 복잡한 선택이 정리되는 느낌 |
| 활용법·다른 사람의 경험을 봄 | 방법과 시행착오를 배움 | 아이디어·배움·교류의 즐거움 |
| 행사·프로모션을 발견함 | 참여·시도 기회를 알게 됨 | 관심 있는 기회를 만난 기대감 |
| 개인 도구·구독을 정리함 | 기록·지출·유지 결정을 관리 | 정돈·절약·자기 관리의 만족 |

재미를 도구 저장 개수나 절약 배지에 한정하지 않는다. 정보의 이해·새 발견·다른 관점·참여 의향도 확인한다. 장시간 체류나 클릭이 자동으로 유익을 증명하는 것은 아니므로 실제로 얻은 내용을 고객의 말로 확인한다.

**대표 고객 경험 — 정보만 얻는 경로와 관리하는 경로를 모두 설계한다.**

| 고객 경로 | 경험의 흐름 | 성공으로 보는 지점 |
|---|---|---|
| 최근 소식 확인 | 홈 → 업데이트/뉴스 → 배경·적용 대상·출처 | 무엇이 달라졌는지 이해하고 나감 |
| 필요한 기능 찾기 | 검색/카테고리 → 도구 상세 → 평가·비교 | 가능한 선택지와 차이를 설명할 수 있음 |
| 사용법 배우기 | 활용 카드 → 예시·단계 → 관련 경험 | 다음에 시도할 방법을 이해하거나 실제 시도 |
| 행사 알아보기 | 소식·행사 → 대상·내용·일정 → 공식 신청 정보 | 자신에게 맞는 기회인지 판단 |
| 개인 관리 | 마이페이지 → 도구·구독 → 비용/절약/해지 안내 | 기록을 정리하고 필요한 행동을 결정 |

앞의 네 경로는 가입·개인 기록 생성 없이 완결되어야 한다. 고객이 원할 때 저장·개별 알림·공개 기여로 이어준다. 검색 결과가 없거나 평가·후기가 부족할 때는 확인 범위와 이유를 설명하고 다른 유용한 정보로 연결한다.

**정보 운영과 데이터 — 공개 지식과 개인 기록을 각각 관리한다.**

공개 정보의 기본 단위는 도구·기능·업무·평가·활용법·기사·업데이트·행사·공개 경험이다. 개인 정보의 기본 단위는 계정·보관 항목·도구 사용 상태·구독 계약·결제·해지 진행·알림 설정이다. 개인 기록이 없어도 공개 정보 사이의 관련성을 탐색할 수 있어야 한다.

| 운영 영역 | 계속 유지할 일 |
|---|---|
| 도구 정보·평가 | 공식 기능·요금제·조건 확인, 같은 과제 평가, 변경 시 재검토 |
| 뉴스·업데이트 | 핵심 사실·맥락·출처 확인, 발생/발표/확인 시점 구분, 수정 이력 |
| 활용 큐레이션 | 예시 작업 재현, 시작 조건·막힘 설명, 대상에 맞는 선정 이유 |
| 행사·프로모션 | 주최·일정·내용·조건·마감 검수, 변경·종료 반영 |
| 커뮤니티 | 질문·기여·업체 관계·신고 처리, 경험과 사실 오류의 구분 |
| 개인 관리 | 기록 보관·복구, 비용 계산·계약 상태, 해지 경로·알림 정확성 |

정보 탐색의 비중을 유지하려면 공개 콘텐츠의 발행·갱신·검수 담당과 시간을 제품 운영 계획에 명시해야 한다. 개인 관리 기능을 개발하면서 공개 정보 운영을 남는 시간에만 하는 계획은 채택하지 않는다. 뉴스 발행량을 억지로 채우기보다 유지할 수 있는 주제와 확인 범위를 정하고, 조사하지 않은 부분은 상태를 표시한다.

각 출시 계획에서 공개 정보의 개선 항목과 개인 관리의 개선 항목을 함께 검토한다. 공유 기반을 별도로 표시해 같은 작업을 양쪽 성과에 중복 집계하지 않는다. 정보 탐색 기능·콘텐츠의 개선이 연속해서 미뤄지면 범위와 순서를 다시 조정한다.

**출시 계획 — 두 축의 최소 경험을 함께 충족한다.**

도구 기본 정보 15~20개, 깊이 평가할 도구 약 6개, 대표 평가 업무 최대 3개, 재현 가능한 안내 약 6개는 기존의 검증 전 운영안으로 유지한다. 공개 소식·업데이트·행사·경험에는 실제 검수한 내용을 제공하며 모든 도구가 평가됐거나 모든 분야를 다룬다고 표시하지 않는다.

| 단계 | 공개 정보·커뮤니티 | 개인 활용·관리 |
|---|---|---|
| 준비 | 대표 정보 질문 수집, 도구 데이터·평가·활용법, 소식·행사 편집 계획 | 서비스·구독 기록, 비용·해지·알림의 최소 흐름과 조건 정리 |
| 첫 공개 | 정보 중심 홈, 카테고리·검색, 도구 상세·평가·비교, 활용법, 뉴스·업데이트·행사 목록, 검수한 경험·질문 접수 | 계정 보관·내 도구함, 수동 구독·비용, 기본 절약 비교, 해지 안내·진행 기록, 관심 프로모션 알림함·동의한 이메일 |
| 반복 개선 | 검색 실패·정보 공백 보완, 공개 콘텐츠 갱신, 비교·활용법 확충, 참여·답변 개선 | 기록 재사용·입력 부담 개선, 개인 조건·알림 정확성, 필요한 복수 구독 비교 |
| 확장 | 분야별 심화 평가·주제 큐레이션·교육·커뮤니티·새 언어 | 팀 도구함·내역 연결·자동화·추가 알림 채널·고급 분석 |

첫 공개의 완료 기준은 두 가지다. **개인 페이지를 쓰지 않는 고객이 필요한 정보·차이·변화를 얻을 수 있어야 하고, 개인 관리를 원하는 고객은 기록·비용·해지·알림의 최소 흐름을 이용할 수 있어야 한다.** 한쪽의 기능 수가 많다는 이유로 다른 쪽의 부족함을 완료로 처리하지 않는다.

일정과 인력이 부족하면 검수할 도구·주제의 폭, 콘텐츠 양, 자동 수집과 복잡한 관리의 깊이를 조정한다. 핵심 공개 탐색을 뒤로 미루고 구독 관리만 먼저 완성하는 방향으로 변경하지 않는다. 각각의 지원 범위와 갱신 상태를 고객에게 알린다.

**검증과 성과 — 정보 획득과 개인 활용·관리를 동등하게 평가한다.**

첫 사용 테스트에서는 정보만 찾는 고객과 개인 관리를 원하는 고객의 과제를 별도로 수행한다. 정보 과제에는 최근 변경 이해, 기능 검색·비교, 활용 방법 설명, 행사 적합성 판단을 포함한다. 개인 과제에는 도구·구독 기록, 기간별 비용 이해, 해지 경로 확인, 관심 알림 설정을 포함한다. 같은 사람에게 모든 과정을 연속으로 강요하지 않는다.

운영 대시보드에는 ‘정보를 얻고 이해하는 데 도움이 됐다고 응답한 이용’과 ‘개인 활용·관리에 도움이 됐다고 응답한 이용’을 각각 표시하고 정보 응답에 비회원 경로를 포함한다. 비회원의 고유 인원을 계정 사용자처럼 정확히 셌다고 표현하지 않으며 동일 방문·반복 응답 처리 기준을 정한다. 두 수치를 단순 합산하거나 임의의 가중 종합 점수로 대체하지 않는다.

정보 관련 응답의 질문·분모·수집 시점과 개인 관리의 사용·재사용 분모를 각각 공개한다. 관찰 기간이 끝나지 않은 사람, 미시도·미응답을 구분한다. 클릭이나 짧은 자기보고만으로 학습·업무 성과가 입증됐다고 주장하지 않는다. 정보의 이해 확인은 선택형 짧은 조사·사용성 테스트로 진행하고 매 기사마다 응답을 요구하지 않는다.

**확장·수익화도 두 축의 가치를 유지한다.** 분야별 심화 정보·비교·교육·행사·커뮤니티 운영과, 고급 개인 정리·비용 분석·팀 관리·자동 동기화를 각각 수요에 따라 검증한다. 일반 정보의 신뢰와 편리한 접근을 유지하고, 제휴 수익이 평가·추천·알림 순서를 결정하지 않게 한다. 가격과 유료 범위는 아직 검증 전이다.
