# Reviewed notification sources

Public source facts come from reviewed catalog/promotions JSON. A retrieval timestamp is not a content revision. Keep each announcement's `latestUpdate.id` stable while correcting it; use a new ID for a different announcement from the same tool. Increment the integer `revision` whenever any material fact changes. Never reuse an older revision after publishing. Date-only deadlines are not absolute instants. Do not fill `expiresInstant` without official time/offset evidence. Use `unknown` for price tax or offer-specific feature inclusion that has not been established.

`notice_source_heads` stores public card identity, reviewed revision, material fingerprint and the revision of the last material transition. Same facts at a later review revision retain the event identity. A→B→A has a new event identity for customers who were told B. Equal revision with different material facts marks a conflict until a higher reviewed revision resolves it. An old worker cannot change the current card, cancel a newer queue, consume its daily slot, or start a stale delivery. Private billing identifiers never enter this shared table.

`notifications` is an immutable version history; `notification_cards` selects the current version for each owner. Existing email payloads, attempts, provider IDs and idempotency keys are never rewritten to fit a correction. Legacy date-only versions have an explicitly held initial baseline when previous facts are unknown. Holding a baseline does not create a successful delivery. Later material corrections remain possible.

Qualification is separate from a corrective notice. Normal offer mail requires current explicit eligibility confirmation and every saved price/period/feature condition. Corrections are only for a previously attempted audience and still require current interest, channel consent and timing limits. A pre-deadline payload, including a correction, is never retried after its original deadline bound. A new verified withdrawal/expired-fact correction may explain the change without encouraging application.
