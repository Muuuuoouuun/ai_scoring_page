# AIs — AI·SaaS 탐색과 활용

한국어 AI·SaaS 정보 탐색, 비교, 커뮤니티와 개인 도구·구독 관리 서비스. 첨부된 디자인은 색감·정보 정리 참고이며 화면 복제 대상이 아니다.

## 실행 및 검증

- `npm ci`, `npm run dev`
- `npx tsc --noEmit`
- `node --test tests/api.test.mjs tests/billing.test.mjs`
- `node scripts/smoke-local.mjs` (로컬 개발 서버 필요)
- Sites 빌드와 배포는 Sites 플러그인으로 진행한다. 등록된 사이트와 D1/R2 바인딩은 `.openai/hosting.json`을 참조한다.

## 데이터 및 평가

`data/catalog.json`의 20개 앱·SaaS·모델, 가이드·행사·프로모션은 공식 출처와 확인일을 가진다. 직접 평가하지 않은 도구는 미평가다. 사용자 평점은 계정·도구별 최신 후기 한 건으로 집계하며, 공식 성능 실험 결과로 표시하지 않는다.

서버의 D1에 계정별 개인 기록, 공개 글, 반응·신고, 갱신 상태를 저장한다. 마이페이지에서 기록을 내보내거나 삭제할 수 있다. 사용자 신원은 Sites의 인증 헤더에서만 읽는다.

## 운영 설정

`.env.example`은 설정 키만 제공한다. 운영 값은 Sites 환경 설정에 저장한다.

- `SITE_URL`: 배포 주소
- `ADMIN_USER_IDS`: 쉼표로 구분한 사이트 인증 사용자 ID. 기본 관리자는 없으며 `/admin`에서 현재 계정 ID를 확인한 뒤 소유자만 설정한다.
- `RESEND_API_KEY`, `EMAIL_FROM`: 이메일 발송 연결. 인증된 발신 주소가 필요하다. 미설정 상태에서는 앱 알림을 제공하고 이메일 신청은 비활성화한다. 이메일은 명시적으로 수신 동의한 로그인 계정 주소로만 전송한다.

사이트 방문 시 오래된 서비스 3개를 시간당 최대 한 번 확인한다. 로그인 사용자는 갱신 현황에서 다음 묶음을 수동 확인할 수 있다(분당 한 번). 로고는 R2에 저장하며 실패하면 확인된 정적 로고를 유지한다. RSS/Atom 글은 공식 피드에 표시한다. 일반 문서 변화는 검토 대상으로 유지하며 자동으로 기능 사실을 확정하지 않는다. 방문이 없는 동안 정기 실행을 보장하는 스케줄러는 포함하지 않는다.

개인 알림은 알림 화면 방문·새로고침 시 관심 서비스, 혜택 자격, 결제 일정을 확인한다. 기록 입력은 실제 외부 서비스 구독·해지·결제를 실행하지 않는다.

이메일 시간 설정은 수신을 끈 상태에서도 저장할 수 있다. 하루 요약은 설정한 시간대·시각 이후 첫 처리에서 새 항목을 한 통에 모으며 빈 검사도 해당 날짜의 요약을 닫는다. 조건 알림은 지정 시각 이후 처리 창에서 최근 24시간 최대 3통이다. 과거 요약을 날짜별로 재생하지 않는다. DST의 사라진 시각은 같은 날짜의 첫 유효한 분, 반복 시각은 이른 시각을 사용한다. 소비한 요약의 다음 날짜 가드는 시간대·방식 변경이나 수신 해제로 초기화하지 않는다. 이전 이메일 설정에 시간 확인 기록이 없으면 명시적으로 확인·저장하기 전까지 발송을 보류한다.

`email_deliveries`는 항목별 기록과 고정한 제공사 요청 내용, 접수 번호·시각 및 시도 상태를 계정별로 보관한다. 동일 묶음은 동일 키와 본문으로 최대 3회, 첫 시도 이후 23시간 안에서만 재시도한다. 수신 해제·주제 숨김은 미발송 대기를 취소하고 불확실한 이전 시도를 보류하며, 이미 시작한 외부 요청을 회수하지 않는다. 접수된 메일을 수신함 도착으로 표시하지 않는다. 접수 내역은 개인 내보내기와 전체 삭제에 포함되며, 내보내기에는 실행 선점 토큰·API 자격 증명이 포함되지 않는다. 예약 실행이나 실제 이메일 수신 확인은 별도의 아직 미연결된 운영 작업이다.

## 선택적 이용 의견

정보 이용 의견과 로그인한 마이페이지의 개인 관리 의견을 구분한다. 창을 직접 열 때 시작 한 건을 기록하며 탭의 임의 토큰+서버 계정+영역+질문 버전으로 중복 시작을 방지하고 최신 응답으로 수정한다. 원본 토큰은 탭에만 보관하며 서버에는 해시를 저장한다. 비회원은 현재 탭 토큰을 유지하는 동안 해당 의견을 수정·삭제할 수 있다. 로그인 의견은 계정 내보내기·전체 삭제에 포함된다. 의견은 운영자에게만 보인다.

관리자는 질문 버전별 직전 30일(UTC)의 **시작 코호트**에 속하는 최신 응답을 본다. 시작·응답·미응답과 비회원/로그인 경로를 따로 표시한다. 도움 됨 비율은 도움 됨 ÷ (도움 됨+일부 도움+도움 안 됨)이며 아직 이용하지 않음·판단 어려움은 제외하고 별도 집계한다. 0분모는 미집계다. 고유 이용자·전체 방문자·개인 기능 사용/재사용이나 실제 업무 성과를 측정한 값이 아니며 두 영역을 합산하지 않는다. 정기 운영·이메일 전달·실제 사용/재사용 측정의 완성을 뜻하지 않는다.

## 검증 기록

과거 초기 검증에서 로컬 자동 검증 21개 및 20개 공개 경로 검증을 통과했다. 최신 회귀 검증은 `node --experimental-strip-types --test tests/*.test.mjs`로 실행한다. 홈의 서버 스트리밍 의존성 검사는 별도 React 서버 조건으로 `node --conditions=react-server --test tests/home-streaming.mjs`를 실행한다. 실제 로그인, 도구 저장·새로고침, 후기 작성·수정·답글, 구독 날짜 저장, 390px 모달과 비용 비교를 브라우저에서 확인했다. 운영 배포 검증은 별도 QA 보고서에 기록한다.
